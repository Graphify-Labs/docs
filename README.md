# Graphify docs

Source for [docs.graphify.com](https://docs.graphify.com), built with [Mintlify](https://mintlify.com). Merges to `main` deploy automatically.

```bash
npx mint@latest dev   # preview at http://localhost:3000
```

Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request. It covers PR checks, frontmatter, terminology, screenshots, and fact-checking.
