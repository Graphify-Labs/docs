Paste these prompts into any agent connected to Graphify. Each one names the tool it should trigger, so you can check that the agent used the graph instead of searching files one by one. Not connected yet? Use [Connect Graphify in Claude](https://claude.ai/directory/graphify) ([Claude.ai and Desktop](/integrations/claude-ai), [Claude Code](/integrations/claude-code)), [Connect to Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=graphify&config=eyJ1cmwiOiJodHRwczovL2FwaS5ncmFwaGlmeS5jb20vbWNwIn0%3D), the [Graphify extension for VS Code](https://marketplace.visualstudio.com/items?itemName=graphify-labs.graphify-mcp), the [Graphify plugin for ChatGPT and Codex](https://chatgpt.com/plugins/plugin_asdk_app_6abe89f7f5d88191b9422522bb8562a4), or [Graphify MCP](/platform/graphify-mcp).

Hosted Graphify lists 63 grammars. Open-source Graphify supports 40 languages (33 tree-sitter, 7 built-in).

<Tip>
Start each session with "Use Graphify's `list_repositories` tool and pick the repository for this project." Most repository tools take that `repository_id`, either the UUID or `owner/name`. You can omit it when the connection URL sets `?repo=` or the workspace has one repository.
</Tip>

## Review a pull request

<PromptBlock text="Use Graphify to review this pull request. For each changed function, call graphify_impact with include_risk to see the code directly connected to it and the hotspot files ranked by linked-test coverage. Call graphify_tests_for on the changed symbols and tell me which tests to run. Cite file paths." />

**Triggers:** `graphify_impact` with `include_risk`, and `graphify_tests_for`. These tools read the graph. They don't run tests. `include_risk` ranks hotspot files by linked-test coverage. That ranking is a signal from the graph, not a verdict.

## Check the impact of a change

<PromptBlock text="Before you change parseConfig, use Graphify's graphify_impact on it and list the code directly connected to it, grouped by file." />

**Triggers:** `graphify_impact`, which takes the symbol name as `target`. It returns the callers and callees directly connected to it. That's a first pass, not every transitive effect. Set `include_risk` to also rank hotspot files by linked-test coverage.

## Find where something is called

<PromptBlock text="Use Graphify's graphify_callers to show every place that calls createSession, with file paths and line numbers." />

**Triggers:** `graphify_callers`, which takes the symbol name as `symbol`. If the name matches several definitions, it refuses and lists the candidate ids. Pass an id to pick one. By default it returns only resolved call edges (`strict_calls` is true). Set `strict_calls` to false to include inferred ones. An empty list means no call edge was indexed. It doesn't prove the code is unused, because dynamic calls can be missed.

## Find the tests for a symbol

<PromptBlock text="Use Graphify's graphify_tests_for to find the tests that cover the billing webhook handler. Tell me which ones to run." />

**Triggers:** `graphify_tests_for`. It accepts a symbol or a file path and returns test files and test functions linked through imports and calls. Linked tests aren't a guarantee of runtime coverage.

## Onboard to a new codebase

<PromptBlock text="I'm new to this repository. Use Graphify: call graphify_rank_files for the most important files, then query_graph to explain how a request flows from the API layer to the database. Keep it to one page and cite files." />

**Triggers:** `graphify_rank_files`, which ranks files for the question, then `query_graph`, which returns the relevant definitions to explain from. For a lighter first look, ask for `graph_stats`, or `query_graph` with `skeleton` so you get outlines instead of full definition bodies.

## Follow a call path

<PromptBlock text="Use Graphify's graphify_trace from the checkout handler to chargeCard. List each directed call path, and say if a path is empty." />

**Triggers:** `graphify_trace`, from `src` to `tgt`. If a name does not resolve, it can fall back to a semantic match. Check `resolved.src` and `resolved.tgt`. An empty path means no directed call path was found in the indexed graph.

## Make it stick

- The graph reflects the last indexed snapshot of the default branch. If your branch has new code, say so and expect gaps. See [Keep answers fresh](/agents/overview#keep-answers-fresh).
- `remember` saves a note for later sessions. Your agent should ask before calling it.
- To make your agent use Graphify without being told, add a project rule. See [Make agents use the graph](/cookbooks/make-agents-use-the-graph).
