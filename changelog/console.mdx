<Update label="2026-10-26" description="A new Dark theme, and the old one is now Pine">
## A new Dark theme, and the old one is now Pine

The console has a new **Dark** theme: a neutral near-black with no tint and stronger contrast. The dark theme you had before, with its green-tinted background, is still here under a new name, **Pine**.

Pick your theme from **Theme** in the user menu, or from the new **Appearance** tab in **Settings**. You can choose **System**, **Light**, **Dark** or **Pine**. The choice is saved in your browser, and Dark is the default on a new device. If you'd picked Dark before, you now get the new neutral Dark, so switch to Pine to keep the green look.

Billing is clearer too. On Free, the plan card shows how many of your 3 indexed repositories you've used. If you start Pro checkout from a repository and back out, the console keeps that repository and your monthly or annual choice, so **Resume checkout** picks up where you stopped. Once payment is confirmed, one click takes you back to the repository you were working on.

### New
- **Billing:** If you're on a trial, Billing shows its end date and your subscription price, with a **Manage trial** button.
- **Agent setup:** While you wait for your agent, a status line tells you whether Graphify has seen its call in this workspace, in another one, or not yet.
- **Agent setup:** Once a repository is indexed, agent setup suggests starter tasks drawn from your code.
- **Overview:** The **Connect agent** button in the header copies a connection prompt you can paste into Claude Code, Codex, Cursor or another agent.

### Improved
- **Themes:** Secondary and error text is easier to read in the dark themes, and error and not-found pages follow your theme.
- **Wiki:** When a repository has no wiki yet, the page says why (not indexed, indexing, paused or failed) and gives you the right button: **Index now**, **Resume indexing** or **Retry indexing**.
- **Repository pickers:** Each repository shows a GitHub or GitLab icon.
- **Console:** Scrollbars are thinner and quieter, and the sidebar no longer shows one.

### Fixed
- **Overview:** **Needs attention** no longer fails when it loads slowly. If it can't load, the tile hides and comes back when fresh data arrives.
- **Wiki:** Switching back to your default repository keeps that choice.

[Read about billing](/pricing/overview)
</Update>

<Update label="2026-10-25" description="Pick a default repository for your agent">
## Pick a default repository for your agent

The MCP setup URL can now pin a default repository, for example `https://api.graphify.com/mcp?repo=acme/api`. Your agent queries that repository unless you name another one.

### Improved
- **Onboarding:** When you finish setup, you land on agent setup so you can connect your agent right away.
- **Onboarding:** Repositories with no commits are refused when you select them, not later when you press **Index**.
- **Onboarding:** If your GitHub installation shares no repositories, the console names the installation and links straight to its settings.
- **Overview:** A **Connect your agent** card stays on the Overview until your agent makes its first call.
- **Onboarding and Settings:** You can see which GitHub permissions Graphify has, and whether access is missing or just could not be checked.

[Read the MCP overview](/mcp/overview)
</Update>

<Update label="2026-10-18" description="Plain-language verification results">
## Plain-language verification results

Verification results now say in plain language what was checked and what changed, and they match the check on your pull request. You can link to a single run with `?run=`.

### New
- **Ask:** The **Applied memory** panel shows which memories informed an answer.
- **Overview:** A **Latest pull request** card shows the review verdict and verification result for the same commit, side by side.
- **Repositories:** Repositories that GitHub reports as deleted, transferred to an account without Graphify, or no longer accessible to the Graphify app show a **No longer on GitHub** label on their row, and owners can remove them.
- **Sign in:** The sign-in page marks the method you used last with a **Last used** label.

### Improved
- **Connectors:** **MCP** opens first, before **Integrations**.
- **Dashboard:** When a rebuild is skipped because nothing changed, the console says so instead of promising a new run.
- **Console:** Page descriptions and empty states are shorter and clearer.

### Fixed
- **Graph:** Repeated labels no longer appear, and square markers are back.
</Update>

<Update label="2026-10-11" description="Add repositories any time">
## Add repositories any time

The **Repositories** page has an **Add** action in its header, so you can connect more GitHub repositories after setup without redoing onboarding.

### New
- **Agent setup:** A **Connect your agent** card appears on the graph page, and the sidebar entry is now **Connect agent**.
- **Agent setup:** Install buttons for official Graphify plugins lead the MCP page.
- **Memory:** The Memory page has **Simple** and **Advanced** views.
- **Memory:** Memories your agent adds automatically are labeled, with one-click **Undo**.
- **Search:** Every repository picker has a search box.
- **Contributors:** The Contributors page has search and a risk filter beside its tabs.

### Improved
- **Product tour:** The tour starts once your first graph is ready and shows agent setup second.
- **Repository connection:** The connection screen is refreshed and Settings is simpler.
- **Memory:** Memory stays off for a repository until its first index finishes.
- **Sign up and sign in:** Buttons show a pending state while you wait.

### Fixed
- **Repositories:** Paused repositories no longer flip back to **Indexed** after a refresh.
- **Billing:** Workspaces with a failed payment stay open during the grace period, with a banner that explains what to do.
</Update>

<Update label="2026-10-04" description="Resend your verification email">
## Resend your verification email

If your sign-up verification email got lost or expired, you can now request a new link from the sign-in page instead of getting stuck.

### Improved
- **Members:** **Last active** shows real activity, from console use and agent calls, as a single line.
- **Keyboard shortcuts:** Hints show `⌘` on macOS and `Ctrl` on Windows and Linux.

### Fixed
- **Sign in:** Failed sign-in callbacks show an error you can act on instead of a blank error page.
- **Notifications:** Toasts appear above open dialogs.
</Update>

<Update label="2026-09-27" description="Find unreferenced code">
## Find unreferenced code

A new card on each repository lists code that nothing references, so you can find candidates to delete. It is hidden on repositories with indexing off.

### New
- **Reviews:** Reviews add advisory notes on risky patterns and documentation that may be out of date, with per-repository settings.

### Improved
- **Repositories:** **Sync** re-reads GitHub, so new repositories and permission changes show up right away.
- **Verifications:** The list is filtered by repository and pages through older runs.
</Update>

<Update label="2026-09-20" description="Tell your agent to reach for the graph">
## Tell your agent to reach for the graph

The connect-agent page has a copy-paste rules card that tells your agent to prefer Graphify over searching files by hand.

### Improved
- **Overview:** The Overview shows a language breakdown for each repository.
- **Billing:** The upgrade button no longer mentions a free trial when none applies.

### Fixed
- **Access:** The Free plan always grants access to the dashboard.
- **Memory:** Links to a memory stay on the right repository.
</Update>

<Update label="2026-09-13" description="A redesigned console">
## A redesigned console

The dashboard, sidebar, loading states, Members page and login page have a new design. Pro workspaces show a **Pro** badge, and the Graphify logo is updated.

### New
- **Graph:** You can cancel an index that is still running.
- **Builds:** Each successful build shows how many nodes it added or removed. **Retry** appears only on the latest build.
- **Repositories:** Each repository's options menu has toggles for **Formal verification** and **Inline health**.

### Improved
- **Repositories:** When a repository cannot be indexed yet, the graph page and repository tile explain why. On the Free plan, you see Pro pricing and can upgrade from there.
- **Onboarding:** The onboarding flow has a new layout and a walkthrough.
- **Contributors:** Rows handle missing GitHub profile details, and a contributor is no longer linked to the wrong GitHub identity.

### Fixed
- **Graph:** The graph page loads behind a skeleton instead of jumping.

[Take the console tour](/platform/console)
</Update>

<Update label="2026-08-30" description="Skip connecting a code host for now">
## Skip connecting a code host for now

Onboarding no longer makes you connect a code host first. You can skip that step, look around the console, and connect a code host later.

### New
- **Contributors:** A **Contributors** page shows who has changed each repository, ranked by reach, with a **Tamper risk** tab for supply-chain risks. [Read about contributors](/platform/contributors)

### Improved
- **Performance:** The console loads your workspace faster on first visit.
- **Billing:** Only owners and billing admins can open the billing portal.
- **Contributors:** Each person appears once, even when they committed under more than one email, and every row opens a profile.
</Update>

<Update label="2026-08-23" description="Clearer pull request diffs">
## Clearer pull request diffs

PR reviews render diffs with a new viewer that uses the same syntax colors as GitHub.

### New
- **Memory and Learning:** Memory and Learning are available to every user.

### Improved
- **Workspaces:** The workspace switcher separates **Your workspace** from workspaces **Shared with you**.
</Update>

- **GitHub:** Connecting retries when a GitHub installation is out of date.
