Ask your agent who calls a function, what it calls, or how one symbol reaches another. Graphify answers from the call edges in the graph of your indexed repository, so your agent follows real links instead of searching for names.

Use this when you already know a symbol and want to see what is around it. If you don't know where to start, [ask a question about your code](/concepts/ask-about-your-code) first.

## Before you start

- An account at [app.graphify.com](https://app.graphify.com). New accounts start on a 14-day Pro trial, then Free (up to 3 repositories), no card required.
- A repository with the status **Indexed**. See [Repositories and builds](/platform/repositories).
- Your agent connected to the hosted MCP server at `https://api.graphify.com/mcp`. See [Code with an agent](/cookbooks/cloud-coding-agents).

## Follow callers and callees

<CodeGroup>

```text Agent prompt
Use Graphify on Graphify-Labs/graphify: what calls build_from_json, and what does it call?
```

</CodeGroup>

Your agent uses these hosted tools:

| Tool | What it returns |
| --- | --- |
| `graphify_callers` | What calls a symbol, from directed call edges. |
| `graphify_callees` | What a symbol calls, from directed call edges. |
| `graphify_references` | References to a symbol that are not calls. |

An empty callers or callees result describes the indexed graph. It does not prove that nothing calls the symbol, for example when code is called dynamically or the index is out of date.

## Trace a path between two symbols

<CodeGroup>

```text Agent prompt
Use Graphify on Graphify-Labs/graphify: how does extract reach build_from_json?
```

```bash Local CLI
graphify path "extract" "build_from_json"
```

</CodeGroup>

| Tool | What it returns |
| --- | --- |
| `graphify_trace` | Directed call paths from one symbol to another. |
| `shortest_path` | The most confident path between two symbols. |

The local `graphify path` command takes these options:

| Option | Meaning |
| --- | --- |
| `--directed` | Respect stored direction. This is the default. |
| `--undirected` | Ignore direction to explore how two symbols connect. |
| `--graph` | The graph file to read. |

## Read the result

A lookup or a trace can return a semantic suggestion when a name has no exact match. Check the labels and resolution fields on the result before you trust a path. Each edge also carries a confidence tag (`EXTRACTED`, `INFERRED`, or `AMBIGUOUS`). [Edges and provenance](/concepts/provenance) explains each tag.

## If something fails

| What you see | What to do |
| --- | --- |
| The wrong symbol is used | Give the full name or the file it lives in. |
| No path found | Try `--undirected` locally, or ask for callers of the target and work backwards. |
| Callers are missing | Check that the latest build of the repository is **Indexed**. |
