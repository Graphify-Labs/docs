Graphify, the hosted product, builds and stores the graph of your repositories and serves it over MCP at `https://api.graphify.com/mcp`. Point your coding agent at that URL, sign in once in the browser, and the agent asks the graph instead of re-reading files every session. There's nothing to install or run.

## What you'll build

- An indexed repository in Graphify.
- An agent connected to the hosted MCP server over Streamable HTTP with OAuth.
- A working first query, and prompts for everyday use.

## Setup

- An account at [app.graphify.com](https://app.graphify.com). The Free plan (up to 3 repositories) needs no card. Pro and Teams start with a 14-day trial, card required.
- At least one repository with the status **Indexed**. The [quickstart](/platform/quickstart) walks through connecting GitHub and switching on **Indexing** from a repository's **…** menu.

## Step 1: Open the MCP connector

In the console, go to **Connectors → MCP**. Setup has three steps: **Choose agent**, **Connect** and **Try a query**. Pick your agent, or open **Browse all agents**.

To let the agent do the setup, choose **Copy quick-start prompt** and paste it into your agent.

## Step 2: Add the server to your agent

**Claude Code** (run in a terminal, not inside a session):

```bash
claude mcp add --transport http --scope user graphify https://api.graphify.com/mcp
```

**Cursor, Claude Desktop and other `mcpServers` clients:**

```json
{
  "mcpServers": {
    "graphify": { "url": "https://api.graphify.com/mcp" }
  }
}
```

**VS Code** (`.vscode/mcp.json`):

```json
{
  "servers": {
    "graphify": { "type": "http", "url": "https://api.graphify.com/mcp" }
  }
}
```

The server is also listed in the MCP registry as `io.github.Graphify-Labs/graphify`. Per-agent details are on [Hosted MCP](/integrations/overview).

## Step 3: Sign in

On first use the agent opens a browser window. In Claude Code, run `/mcp`, pick **graphify** and choose to authenticate. Sign in to Graphify and approve access. There's no API key to paste or store.

## Step 4: Check the connection

Paste the test prompt from **Try a query**, or ask:

```text
Use Graphify's list_repositories tool and show the repositories I can access.
```

The list should match your workspace. If you belong to more than one, ask the agent to use `list_workspaces` and `set_workspace` first.

## Step 5: Ask about your code

Name the symbol, file or area you care about:

- `Who calls the function that validates a session token?`
- `What would break if I changed this module's public interface?`
- `Which tests cover the billing webhook handler?`
- `Trace how a request reaches the billing service.`

The agent picks tools such as `graphify_find`, `graphify_callers`, `graphify_impact`, `graphify_tests_for` and `graphify_trace`. You don't call them by hand.

## Step 6: Give the agent memory

Ask the agent to record decisions as it works:

```text
Remember that payments retries are capped at 3 because of the provider's rate limit.
```

The agent stores this with `remember` and finds it later with `recall`. Inspect and remove entries on the [Memory](/platform/memory) page.

## When it goes wrong

**No browser window opens.** Some agents need a restart after you add a server. Restart it, then run a tool again.

**`list_repositories` returns nothing.** The repository isn't indexed yet, or the agent is in another workspace. Check the status in **Repositories**, then use `set_workspace`.

**The agent answers without Graphify.** Name the tool or say "use Graphify" in the prompt. Some agents only call MCP tools when asked.

## Production patterns

- Add the server at project scope (`.mcp.json` or `.vscode/mcp.json`) and commit it, so teammates connect with one sign-in.
- Check pull requests your agent opens on the [Reviews](/platform/reviews) page.
- Open the [Graphs](/platform/graphs) and [Wiki](/platform/wiki) pages when an answer needs a closer look.
- To keep everything on your own machine, use the open-source CLI instead: [Give Claude Code a graph of your monorepo](/cookbooks/claude-code-monorepo).

## Complete example

```bash
# 1. Index a repository at app.graphify.com
# 2. Connect Claude Code
claude mcp add --transport http --scope user graphify https://api.graphify.com/mcp
# 3. In Claude Code, run /mcp and finish the browser sign-in, then ask:
#    "Use Graphify's list_repositories tool and show my repositories."
```

## What you built

Your agent queries a graph we build and host. It answers questions about callers, impact and tests from indexed repositories, and remembers decisions across sessions.
