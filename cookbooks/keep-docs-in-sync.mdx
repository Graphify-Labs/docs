Docs drift. A function is renamed or its behavior changes, and the README, the runbook and the design doc still describe the old version. Graphify connects docs to the code they mention, so a pull request can flag the docs it may have made stale.

This walkthrough uses the open-source [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) repository, whose docs sit next to its code.

## Walk through it

<Steps>
  <Step title="Index the repository">
    Connect it on **Repositories** and wait for **Indexed**. See [Index your first repository](/concepts/index-a-repository) and [Repositories and builds](/platform/repositories).
  </Step>
  <Step title="Turn on stale-docs checks">
    On **Repositories**, open **Options** for the repository and check that **Stale docs** is on. It is on unless someone turned it off.
  </Step>
  <Step title="Change some code">
    Open a pull request that renames or changes a function the docs mention. The review can include **Docs that may be stale (advisory)**, listing docs that mention the code you changed. See [Pull request reviews](/platform/reviews).
  </Step>
  <Step title="Bring in docs outside the repository">
    Connect a Google Drive folder so your workspace and agents can search those documents next to your code. See [Connect Google Drive](/integrations/google-drive).
  </Step>
</Steps>

The list is a prompt to check, not a verdict. A doc can mention a function without describing the part that changed.

The [Wiki](/platform/wiki) is generated alongside the code graph, so it follows each index of the default branch.

## Do it locally instead

Keep the local graph current as you work, so your assistant reads docs and code from the same state:

```bash
graphify hook install
graphify update .
```

The hooks refresh the graph after commits and branch switches. Run `graphify update .` after a pull or a merge. Docs and PDFs go through a semantic pass with your assistant's model or a configured backend, such as a local Ollama. See [Keep the graph current](/open-source/features/incremental-updates).
