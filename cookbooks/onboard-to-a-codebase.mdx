You have joined a project, or picked up a repository you didn't write. Reading files one by one is slow, and search only finds names you already know. Graphify gives you a map first: the main areas of the code, how they connect, and answers that cite the definitions they came from.

This walkthrough uses the open-source [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) repository. Index a fork of it to follow along.

## Walk through it

<Steps>
  <Step title="Index the repository">
    Connect the repository on **Repositories**, switch on **Indexing**, and wait for **Indexed**. See [Index your first repository](/concepts/index-a-repository) and [Repositories and builds](/platform/repositories). The Free plan covers 3 repositories, with no card.
  </Step>
  <Step title="Read the map">
    Open **Graphs** to see the nodes and the most connected areas. Then open **Wiki**, which has an article for each area of the repository, linked to the code it describes. See [Wiki](/platform/wiki).
  </Step>
  <Step title="Ask where things live">
    Connect your agent to `https://api.graphify.com/mcp` ([Code with an agent](/cookbooks/cloud-coding-agents)). Setup pages: [Claude Code](/integrations/claude-code), [Cursor](/integrations/cursor), [Codex](/integrations/codex) or [VS Code](/integrations/vscode).

    Then ask:

    ```text
    Use Graphify on Graphify-Labs/graphify: what happens between extract and build_from_json?
    Show the files and definitions you used.
    ```

    See [Ask a question about your code](/concepts/ask-about-your-code).
  </Step>
  <Step title="Follow the calls">
    Pick a function from the answer and ask what calls it and what it calls. See [Follow calls and trace a path](/concepts/follow-calls).
  </Step>
</Steps>

Answers are graph evidence. Each relationship carries a tag: `EXTRACTED` is written in the source, `INFERRED` is worked out by Graphify, and `AMBIGUOUS` is flagged by the model pass. Open the source before you rely on an answer.

## Do it locally instead

```bash
uv tool install graphifyy
git clone https://github.com/Graphify-Labs/graphify && cd graphify
graphify extract . --code-only
graphify query "what happens between extract and build_from_json"
graphify explain "build_from_json"
```

`--code-only` parses the code locally without a model. Open `graphify-out/GRAPH_REPORT.md` for the main areas of the code, and `graphify export html` writes an interactive graph. See [Run Graphify locally](/open-source/local-development).
