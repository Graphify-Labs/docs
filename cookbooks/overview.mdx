Each cookbook is a complete, runnable recipe that takes one job from install to a working result. They run on the open-source [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) CLI, with notes where Graphify, the hosted product, does the work for you.

## Essentials

<Columns cols={2}>
  <Card title="Understand a new codebase in 30 minutes with Graphify" icon="compass" href="/cookbooks/onboard-to-a-codebase">
    Understand a new codebase in 30 minutes: build a knowledge graph, read its report and hub nodes, then ask questions that cite real files and lines.
  </Card>
  <Card title="Plan a refactor with code impact analysis" icon="compass" href="/cookbooks/plan-a-refactor">
    Run code impact analysis before a refactor: list every caller of a function, trace paths between modules, and find the tests to run, with Graphify.
  </Card>
  <Card title="Keep docs in sync with code using git hooks" icon="compass" href="/cookbooks/keep-docs-in-sync">
    Keep docs in sync with code: rebuild the Graphify graph on every commit with git hooks or watch mode, then regenerate a code wiki that never goes stale.
  </Card>
</Columns>

## Team

<Columns cols={2}>
  <Card title="Review pull requests as a team with a code graph" icon="users" href="/cookbooks/review-as-a-team">
    Review pull requests as a team with Graphify: rank open PRs by impact, spot PRs that collide on the same code, and pick a safe merge order early.
  </Card>
  <Card title="Share a code graph with your team using git" icon="users" href="/cookbooks/shared-team-graph">
    Share one code graph with your team: commit graph.json, register Graphify's git merge driver so branches merge cleanly, and tag who added each source.
  </Card>
  <Card title="Map dependencies across multiple repositories" icon="users" href="/cookbooks/cross-repo-dependencies">
    Combine two or more repositories into one cross-repo dependency graph, then ask your coding agent what a change in one repository breaks in the others.
  </Card>
</Columns>

## Agents

<Columns cols={2}>
  <Card title="Give Claude Code a knowledge graph of your monorepo" icon="bot" href="/cookbooks/claude-code-monorepo">
    Give Claude Code a knowledge graph of your monorepo: install the Graphify skill, add always-on hooks and a local MCP server, then measure token savings.
  </Card>
  <Card title="Connect cloud coding agents to hosted MCP" icon="bot" href="/cookbooks/cloud-coding-agents">
    Connect Claude Code, Codex, Cursor or VS Code to Graphify's hosted MCP server, sign in with OAuth, and let your agent query indexed repositories.
  </Card>
  <Card title="Make your coding agent actually use the graph" icon="bot" href="/cookbooks/make-agents-use-the-graph">
    Get Claude Code, Codex and Cursor to query Graphify before they grep, keep the graph fresh as code changes, and prove the agent called the tools.
  </Card>
  <Card title="Build a fully local code knowledge graph with Ollama" icon="bot" href="/cookbooks/local-with-ollama">
    Build a code knowledge graph that never leaves your machine: parse code offline, then run Graphify's semantic extraction on a local Ollama model.
  </Card>
</Columns>

## Data

<Columns cols={2}>
  <Card title="Graph your Postgres schema next to your code" icon="database" href="/cookbooks/postgres-schema-graph">
    Add your PostgreSQL schema to your code graph: Graphify reads tables, views, functions and foreign keys over a read-only connection, next to your code.
  </Card>
  <Card title="Load your code knowledge graph into Neo4j" icon="database" href="/cookbooks/neo4j-export">
    Export your Graphify code graph to Neo4j as a Cypher script or push it straight to a database, then query callers and dependencies in Cypher.
  </Card>
  <Card title="Turn meeting recordings into a knowledge graph" icon="database" href="/cookbooks/meetings-and-videos">
    Transcribe meeting recordings, talks and YouTube videos with Whisper, then add the transcripts to your Graphify knowledge graph next to your code.
  </Card>
</Columns>
