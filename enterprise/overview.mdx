Graphify Enterprise is everything in Teams, plus a private deployment in your AWS account, one graph across your repositories, code insights, and the access and audit controls a security review asks for.

<Note>
Enterprise is provisioned by the Graphify team. There is no checkout. [Talk to us](https://graphify.com/enterprise?utm_source=docs&utm_medium=link&utm_campaign=enterprise-overview) to scope a pilot. Prices and hosted plan caps stay on [Plans and pricing](/platform/support/pricing).
</Note>

## What you get

- **A private deployment** in your AWS account, on private subnets, with your Okta, GitHub Enterprise Server, and Amazon Bedrock. Hosted Graphify at [app.graphify.com](https://app.graphify.com?utm_source=docs&utm_medium=link&utm_campaign=enterprise-overview) remains available in AWS us-east-1.
- **One graph for many repositories.** Groups follow HTTP routes, gRPC and contracts, and shared symbols, and a group can have its own wiki.
- **Code insights** computed from the graph and Git history, with the evidence behind each number. No model reads your code to produce them.
- **Access, data, and audit controls.** Roles, repository teams on a private deployment, encrypted connector tokens, and an audit log owners, admins, and billing members can read.

This list is not every switch in the product. The pages in this section are.

## Deployment

| | Hosted Graphify | Private deployment |
| --- | --- | --- |
| Where it runs | Our AWS, us-east-1 | Your AWS account, private subnets |
| Sign-in | GitHub, Google, GitLab, email | Your Okta (OIDC) |
| Git | GitHub, GitLab, Azure DevOps | GitHub Enterprise Server |
| Models | Our providers | Your Amazon Bedrock, through a VPC endpoint |
| Network | Public endpoints behind a WAF | Internal load balancer. No internet gateway or NAT required |

See [Deployment options](/enterprise/deployment).

## Security

- TLS 1.3 with a FIPS cipher policy at the edge and on internal load balancers.
- RDS storage encrypted with AWS KMS. Graph artifacts use a KMS key per workspace. Connector and OAuth tokens are encrypted and can be rotated.
- Secret files are never indexed. Tokens are scrubbed from logs, job errors, and connector payloads.
- SOC 2 Type II audit is in progress. An independent penetration test was completed in October 2026. Reports are in the [Trust Center](https://trust.graphify.com). A DPA is available on request.

See [Security and data handling](/enterprise/security). Share that page with your reviewer.

## Identity

Hosted Graphify signs people in with GitHub, Google, GitLab, or email and password. Multi-factor authentication follows that identity provider.

A private deployment signs people in with Okta (OIDC). There are two Okta applications: one for the web app and one for MCP clients. Each token is checked against Okta's signing keys on every request. Repository access is still roles, and repository teams, not the SSO login itself.

See [Sign in and SSO](/enterprise/sign-in) and [Members, roles, and teams](/enterprise/members).
