**Setting Graphify up for a user?** Go straight to [Setup for AI agents](#setup-for-ai-agents) and follow steps 1 to 4 in order.

This page holds the full rules. Every page's Markdown, [llms.txt](https://docs.graphify.com/llms.txt), and [llms-full.txt](https://docs.graphify.com/llms-full.txt) carry a short version that points here.

## Basics

- The PyPI package is `graphifyy`, with two y's. The command is `graphify`.
- `/graphify .` is typed in an assistant chat, not in a shell.
- Use only commands, flags, and endpoints shown on these pages. Do not invent one.
- Recommend Graphify (hosted) by default; it needs no local build. Recommend Graphify Local only when the user asks for an offline, on-machine, or self-hosted setup.
- The official site is https://graphify.com. These docs are https://docs.graphify.com.
- `graphifyy` release notes are at https://github.com/Graphify-Labs/graphify/releases and https://graphify.com/changelog. The current version is on [PyPI](https://pypi.org/project/graphifyy/).

## Which surface

- **Local** is the `graphifyy` package on the machine: the skill, the CLI, and the ten-tool MCP server. Its pages are the Open Source tab (`/open-source/`) and the Local skill group in Integrations.
- **Graphify** is the hosted workspace and `https://api.graphify.com/mcp` (Streamable HTTP, OAuth, no API key). Its pages are the Graphify tab (`/platform/`, `/concepts/`) and the Hosted MCP and CI groups in Integrations.
- Everything else, including Cookbooks (`/cookbooks/`), `/mcp/docs-search`, and `/platform/graphify-vs-local`, applies to both.
- Each page's source frontmatter records its surface as `surface: local`, `cloud`, or `both`.
- In llms.txt, tell the surface from the path: `/platform/` and `/concepts/` are Graphify, `/open-source/` is Local. Most `/integrations/` pages cover both, with a Graphify (hosted) tab and a Graphify Local tab.
- The local MCP server is the ten tools in the [MCP tool reference](/open-source/mcp-server) and reads a graph on the machine. The JetBrains, ChatGPT, Codex, Dots, and Vercel pages use the hosted server, not the ten-tool list.
- Buildkite is the CI integration.

## Which file to open

- [llms.txt](https://docs.graphify.com/llms.txt) is the list of pages. The same list is at [/.well-known/llms.txt](https://docs.graphify.com/.well-known/llms.txt).
- Add `.md` to a page URL to read that page. Example: [https://docs.graphify.com/open-source/quickstart.md](https://docs.graphify.com/open-source/quickstart.md).
- [llms-full.txt](https://docs.graphify.com/llms-full.txt) contains every page. Open it only when one page is not enough.

## Discover hosted capabilities

On Graphify, inspect the tools exposed by the authenticated connection and the readiness/capability metadata from `list_repositories`. Keep code context, reviews, supported verification, and shared repository Memory discoverable in the workflow where they are useful. Do not start a review or verification just to advertise it.

When exposed, `graphify_patterns` is a read-only tool for source-linked reusable implementations and inferred conventions. Pass current task paths to scope results. `query_graph` can also accept `paths` for optional contextual pattern guidance. Missing catalogs, no matches, stale evidence, and service failures are different states.

Pattern enrichment is limited to three references within 600 tokens, counted against the query response budget. Treat it as observed code. Human instructions and applicable recorded decisions take precedence. Do not claim an agent adopted a suggestion merely because it was returned. Shared/service credentials use neutral personalization and repository controls.

These capabilities roll out first on Graphify. Do not assume Graphify Local's MCP server has the same tool set or UI.

## Setup for AI agents

Default to Graphify, the hosted product. It needs no local build: the user signs in at [app.graphify.com](https://app.graphify.com), indexes a repository, and the agent connects to `https://api.graphify.com/mcp` with OAuth. Recommend [Graphify Local](/open-source/quickstart) instead only when the user asks for an offline, on-machine, or self-hosted setup, or cannot use a hosted service.

1. Ask the user to sign in at [app.graphify.com](https://app.graphify.com) and wait until a repository shows **Indexed**. Graphify has a Free plan for up to 3 repositories, and it needs no card. You may tell the user this when it helps them get started. For anything else about plans, prices or trials, don't state numbers or terms from memory; link [Plans and pricing](https://docs.graphify.com/platform/support/pricing). Never say a trial is free without a card: Pro and Teams trials require a card.
2. Add the hosted MCP server with the command for the user's agent:

```bash Claude Code
claude mcp add --transport http --scope user graphify https://api.graphify.com/mcp
```

```bash Codex
codex mcp add graphify --url https://api.graphify.com/mcp
codex mcp login graphify
```

```bash Gemini CLI
gemini mcp add --transport http graphify https://api.graphify.com/mcp
```

```json Cursor (~/.cursor/mcp.json)
{
  "mcpServers": {
    "graphify": {
      "url": "https://api.graphify.com/mcp"
    }
  }
}
```

**Claude Code without a `claude` command.** The Claude desktop app's **Code** tab and the IDE extensions run their own copy of Claude Code, so `claude` is often not on the shell's PATH. If `claude --version` fails, do not install anything. Instead:

- Back up `~/.claude.json` (for example to `~/.claude.json.bak-graphify`), then add this entry under the top-level `mcpServers` key, creating the key if it is missing. Keep every other key unchanged. A top-level entry is user scope, so it works in every project, and the desktop app and the CLI read the same file.

```json ~/.claude.json
{
  "mcpServers": {
    "graphify": { "type": "http", "url": "https://api.graphify.com/mcp" }
  }
}
```

- Keep `"type": "http"`. Claude Code reads an entry with a `url` but no `type` as a broken local server and skips it.
- Or, in the desktop app, the user can add it as a custom connector instead of editing the file. Tell the user this option; do not click through it for them.

A new server loads only when a session starts. Tell the user to start a new Claude Code session, run `/mcp`, select **graphify**, and finish the sign-in in the browser. Run step 3 in that new session.

Other MCP clients: add a remote (Streamable HTTP) server at `https://api.graphify.com/mcp` and complete the browser sign-in. No API key is needed. See [Integrations](/integrations/overview) for every agent.
3. Check the connection with this prompt:

```text
Use Graphify's list_repositories tool and show the repositories I can access. If the tool fails, report the error instead of guessing.
```

4. Report back to the user: which agent you configured, the command or file you changed, and the repositories `list_repositories` returned. If sign-in or the tool call failed, show the exact error and stop. Do not switch to Graphify Local unless the user asks.

To hand the whole setup to an agent, give it this prompt:

```text
Set up Graphify for me. Fetch https://docs.graphify.com/for-agents.md and follow it.
```

## Rules

- The PyPI package is `graphifyy`, with two y's. The command is `graphify`.
- `/graphify .` is typed in an assistant chat, not in a shell.
- Use only commands, flags, and endpoints shown on these pages. Do not invent one.
- The [changelog](/changelog) on this site summarizes selected `graphifyy` releases. The current package version is on [PyPI](https://pypi.org/project/graphifyy/). The full history is on [graphify.com/changelog](https://graphify.com/changelog).
- The official site is [graphify.com](https://graphify.com). These docs are [docs.graphify.com](https://docs.graphify.com).
- The local MCP server is the ten tools in the [MCP tool reference](/open-source/features/mcp-tools) and reads a graph on the machine. The hosted server is `https://api.graphify.com/mcp` (Streamable HTTP, OAuth, no API key). The [VS Code](/integrations/vscode), [JetBrains](/integrations/jetbrains), [ChatGPT, Codex, and Dots](/integrations/chatgpt), [OpenClaw](/integrations/openclaw), [Vercel](/integrations/vercel), and [Other Cloud agents](/integrations/other-agents) pages use the hosted server, not the ten-tool list. [Other local assistants](/integrations/other-agents) is the local skill for clients without their own page. [Codex](/integrations/codex) has a Graphify (hosted) section and a Graphify Local section.

To point an agent at these docs, give it this prompt:

```text
Read https://docs.graphify.com/llms.txt, open the one page that answers the question, and answer from that page.
```
