Connect [Claude.ai](https://claude.ai) and the Claude desktop app to Graphify's hosted MCP server at `https://api.graphify.com/mcp`. Claude can then search the repositories indexed in your [Graphify](https://app.graphify.com?utm_source=docs&utm_medium=link&utm_campaign=integrations-claude-ai) workspace, follow callers and dependencies, and check what a change reaches.

Graphify is listed in Anthropic's [Connectors directory](https://claude.ai/directory/graphify). It is a connector. The server uses Streamable HTTP and OAuth. There is no API key to paste.

</InstallButton>

For Claude Code (CLI, IDE, or the desktop Code tab), see [Graphify for Claude Code](/integrations/claude-code).

## Before you start

- A Graphify account. If you don't have one yet, you can create one for free while connecting. The Free plan needs no card. See [Plans and pricing](/platform/support/pricing).
- At least one repository with the status **Indexed**. The [quickstart](/platform/quickstart) connects GitHub and starts indexing. Indexing status is on [Repositories and builds](/platform/repositories).
- A Claude account. Connectors work on Claude.ai, the desktop app, and Claude mobile. On Team and Enterprise plans, an Owner adds the connector for the organization, and members then connect with their own account.

## Connect from the directory

1. Open [Graphify in the Claude directory](https://claude.ai/directory/graphify).
2. Select **Connect to Claude** and finish Graphify sign-in in the browser. Or open **Customize → Connectors**, select **Discover**, and search for Graphify. If you don't have a Graphify account yet, you can create one while connecting. Create a workspace, connect GitHub, and enable a repository before you expect code answers.
3. In a chat, select **+**, then **Connectors**, and turn **Graphify** on for that conversation. The toggle is per chat.
4. Ask about your indexed code. The first tool call may ask you to select **Allow once** or **Always allow**.

### Team and Enterprise

On a Team or Enterprise plan, **Connect to Claude** appears after the connector is available for the organization. Otherwise you may see **Request**, or a note to ask an Owner. An Owner sees **Connect for your team**, and can choose **Connect just for me**.

### Desktop and mobile

The same connector is available in the Claude desktop app and on Claude mobile after you connect it. A desktop extension is a different install. Graphify uses the remote connector.

## Custom connector

If you are not using the directory listing, open **Customize → Connectors**, select **Add**, then **Custom** and **Web**, and enter:

```text
https://api.graphify.com/mcp
```

You still sign in with OAuth. There is no API key.

## Check the connection

With Graphify enabled for the chat, paste:

```text
List the repositories I can access in Graphify. If a tool fails, report the error instead of guessing.
```

The list should match the workspace you chose when you signed in. Then name a repository and ask something concrete:

- `Who calls the function that validates a session token?`
- `What would break if I changed this module's public interface?`

Answers are graph evidence from files Graphify indexed, not a verified result. Open the source lines an answer cites before you rely on it. Some tools write workspace memory, so read each tool request before you approve it.

For a deeper checklist across clients, see [Check your agent is using Graphify](/platform/verify-connection).

## Permissions

| | |
| --- | --- |
| **Auth** | Browser OAuth (PKCE). Scope `graphify:query`. No API key in the URL or chat. |
| **Data** | Indexed repositories in the Graphify workspace you pick at sign-in. Graphify does not read local files from Claude.ai. |
| **Per chat** | Graphify stays off until you enable it under **+**, then **Connectors**, for that conversation. |
| **Tool prompts** | Claude may ask **Allow once** or **Always allow** before a Graphify tool runs. |

## Troubleshooting

| What you see | What to do |
| --- | --- |
| A Claude chat doesn't use Graphify | Select **+**, then **Connectors**, and turn Graphify on for that chat. Approve the tool call if Claude asks. |
| **Request** instead of Connect | Ask an Owner to add the connector for the organization, or choose **Connect just for me** if you are an Owner. |
| Tools return no repositories | The repository is not indexed yet, or it is in a different workspace. Check [Repositories and builds](/platform/repositories). |
| Sign-in loop or denied access | Finish Graphify sign-in in the browser, pick the workspace, and turn the chat toggle on again. |
| Only a `graphify_setup` tool appears, or Claude shows **Graphify isn't set up for this account yet** | Sign-in worked, but this account has no Graphify workspace yet. Open [onboarding](https://app.graphify.com/onboarding?utm_source=docs&utm_medium=link&utm_campaign=integrations-claude-ai), create a workspace, connect GitHub, enable a repository, wait until it is **Indexed**, then start a **new** chat. If tools still don't appear, disconnect and reconnect Graphify in Claude. |
| Tools say **This workspace has no repositories enabled for agents yet.** | In [Graphify](https://app.graphify.com?utm_source=docs&utm_medium=link&utm_campaign=integrations-claude-ai), open **Repositories**, enable a repository, wait for the first index to finish, then ask again. |
| Claude says it couldn't retrieve a result, or shows a generic error | Claude can hide Graphify's error text. Wait a few seconds and ask again. If it keeps failing, check the repository in [Graphify](https://app.graphify.com?utm_source=docs&utm_medium=link&utm_campaign=integrations-claude-ai) for a plan message, then see [Claude shows a generic error](/platform/support/troubleshooting#claude-shows-a-generic-error). |
| Answers miss recent code, or the repository page says **Showing an older graph** | On the Free plan, a repository over its graph limit keeps serving the last graph that fit. Upgrade in **Billing** to use the latest build. See [Plans and pricing](/platform/support/pricing#hosted-plan-allowances). |
| Browser shows **Finish setting up Graphify** after connect | Create a workspace and connect a repository with the **same** account you used to connect, then continue. The connect window should return to Claude. |

## FAQ

### Do I need an API key?

No. The directory connector and a custom connector both sign in with OAuth in your browser.

### Do I need a Graphify account before I connect?

Yes, but you don't have to create it first. If you don't have one yet, you can create one for free while connecting. You still need an indexed repository before Graphify can answer questions about your code.

### Is this the same as Claude Code?

No. This page is Claude.ai, Desktop, and mobile. For the Claude Code CLI and IDE, see [Graphify for Claude Code](/integrations/claude-code).

### Is Graphify a Claude plugin?

No. Graphify is a connector in Anthropic's Connectors directory. A plugin is a separate package that can bundle skills, connectors, and commands.

### Is the hosted server free?

The Free plan (up to 3 repositories) needs no card. Pro and Teams start with a 14-day trial, card required. See [Plans and pricing](/platform/support/pricing). Free has limits on repositories and graph size. When you reach one, Graphify shows a message in the app. See [Rate limits and plan limits](/platform/support/rate-limits#other-limit-responses).
