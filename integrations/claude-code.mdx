## Install and register

```bash
uv tool install graphifyy
graphify install --platform claude
```

The integration writes Claude instructions and PreToolUse hooks that suggest consulting the graph for codebase questions. Exact destinations depend on whether you use a personal or project installation; the installer reports the files it writes.

For a repository-local setup, run this from the project root:

```bash
graphify install --project --platform claude
```

## Build the graph

Open your project in Claude Code. Select the Graphify skill and enter:

```text
/graphify .
```

The assistant runs the Graphify workflow and writes `graphify-out/`. Code extraction runs locally; semantic extraction can use your assistant’s model for documents and media.

## Ask with context

After the graph is built, ask:

> Use Graphify to explain the authentication flow. Cite the source files and distinguish explicit relationships from inferred ones.

You can also query from a terminal:

```bash
graphify query "authentication flow"
```

## Keep the integration current

```bash
uv tool upgrade graphifyy
graphify install --platform claude
```

If the skill is missing, refresh the assistant and confirm that the registration was installed in the intended user or project scope. See [troubleshooting](/troubleshooting).
