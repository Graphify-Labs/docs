Graphify Cloud answers from repositories you have already indexed. Every install below uses the hosted MCP server at `https://api.graphify.com/mcp`.

Sign in at [app.graphify.com](https://app.graphify.com) and wait until the repository status is **Indexed**. The graph stays in Graphify Cloud.
