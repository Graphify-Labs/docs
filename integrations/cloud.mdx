Graphify Cloud answers from repositories you have already indexed. Every install below uses the hosted MCP server at `https://api.graphify.com/mcp`.

Sign in at [app.graphify.com](https://app.graphify.com) and wait until the repository status is **Indexed**. The graph stays in Graphify Cloud.

Codex and OpenClaw each have a local skill too. [Graphify with Codex](/integrations/codex) builds the graph on your machine, and so does `graphify install --platform claw` on [Other local assistants](/integrations/other-assistants). Every other MCP client uses [Other Cloud agents](/integrations/other-agents). Both paths are on [Choose your coding assistant](/integrations/overview).
