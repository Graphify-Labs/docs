Copilot CLI and Copilot Chat in VS Code use different integration paths. Choose the environment you actually run.

<Tabs>
  <Tab title="Copilot CLI">
    ```bash
    uv tool install graphifyy
    graphify install --platform copilot
    ```

    The installer registers the Graphify skill for Copilot CLI. Ask your assistant to use that skill to map the repository, then query the saved graph for codebase questions.
  </Tab>
  <Tab title="VS Code">
    ```bash
    uv tool install graphifyy
    graphify vscode install
    ```

    This uses the VS Code integration and instructions supported by the Graphify installer. You can also configure a [graph MCP server](/mcp/overview) in VS Code for structured tool access.

    To query repositories indexed in Graphify Cloud instead of a local graph, install the [Graphify MCP extension](/integrations/vscode).
  </Tab>
</Tabs>

## Verify the graph

```bash
graphify query "application entry points"
```

If `graphify-out/graph.json` does not exist yet, run the [quickstart](/quickstart) or build with `graphify extract . --code-only`.
