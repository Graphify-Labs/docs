<Tab title="Graphify (hosted)">

Connect Cursor to Graphify's hosted MCP server at `https://api.graphify.com/mcp`. Cursor can then search the repositories indexed in your [Graphify](https://app.graphify.com) workspace, follow callers and dependencies, and check what a change reaches, without re-reading every file.

The server uses Streamable HTTP and OAuth. You sign in once in the browser, so there is no API key to paste and no local process to run.

## Before you start

- A Graphify account at [app.graphify.com](https://app.graphify.com). New accounts start on a 14-day Pro trial, then move to Free (up to 3 indexed repositories). No card is required.
- At least one repository with the status **Indexed**. The [quickstart](/platform/quickstart) connects GitHub and starts indexing. Indexing status is on [Repositories and builds](/platform/repositories).

## 1. Add the server


**One-click install**

In the console, open **Connectors → MCP**, choose **Cursor**, and select **Install in Cursor**. Cursor opens and asks you to confirm the `graphify` server.

**Edit mcp.json**

Add Graphify to `~/.cursor/mcp.json` to use it in every project:

```json ~/.cursor/mcp.json
{
  "mcpServers": {
    "graphify": {
      "url": "https://api.graphify.com/mcp"
    }
  }
}
```

To scope it to one repository, put the same entry in `.cursor/mcp.json` at the repository root. Keep any other servers already in the file.

## 2. Sign in

Cursor shows **Needs login** next to `graphify` until you finish the one-time sign-in. Open Cursor's MCP settings, select **graphify**, and complete the sign-in in your browser. Pick the workspace that holds your repositories.

The desktop app signs in through a local callback. Cursor's web Background Agents on cursor.com use their own hosted callback, which Graphify also allows.

## 3. Check the connection

Open an agent chat in Cursor and paste:

```text
Use Graphify's list_repositories tool and show the repositories I can access. If the tool fails, report the error instead of guessing.
```

This is the same test prompt the console shows on **Connectors → MCP → Try a query**. Check that the list matches the workspace you chose when you signed in.

### Optional: set a default repository

Add `?repo=owner/name` to the endpoint, for example `https://api.graphify.com/mcp?repo=Graphify-Labs/graphify`. Graphify uses that repository when a tool call names none. A repository named in the call still wins.

## 4. Ask a question

Pick a repository from the list and name the symbol, file, or area you care about:

- `Who calls the function that validates a session token?`
- `What would break if I changed this module's public interface?`
- `Summarize how requests reach the billing service.`

Answers are graph evidence from the files Graphify indexed, not a verified result. Open the source lines an answer cites before you rely on it. Some tools write workspace memory, so read each tool request before you approve it.

## Troubleshooting

| What you see | What to do |
| --- | --- |
| **Needs login** next to `graphify` | Select it in Cursor's MCP settings and finish the browser sign-in. |
| `graphify` is missing from the MCP list | Check that `mcp.json` is valid JSON and the entry is inside `mcpServers`, then reload Cursor. |
| The tools return no repositories | The repository is not indexed yet, or it is in a different workspace. Check [Repositories and builds](/platform/repositories). |
| Every Graphify tool appears twice | You have the server in both `~/.cursor/mcp.json` and `.cursor/mcp.json`. Remove one. |

## FAQ

### Do I need an API key to connect Cursor to Graphify?

No. Cursor signs in with OAuth in your browser the first time it connects. There is no key to paste or store.

### Does Graphify read my local files from Cursor?

No. The hosted server answers from repositories already indexed in your Graphify workspace. To build a graph from files on your machine instead, use the open-source package and its local skill.

### Is the Graphify MCP server free?

Every new account starts on a 14-day Pro trial. After the trial, the Free plan keeps the hosted server available for up to 3 indexed repositories, with no card required. See [Plans and pricing](/platform/support/pricing) for Pro and Teams.

### Does Graphify work with Cursor Background Agents?

Yes. Background Agents on cursor.com sign in through Cursor's hosted callback, which Graphify allows.

<Tab title="Graphify Local">

## 1. Install and register

```bash
uv tool install graphifyy
graphify install --platform cursor
```

The integration installs the skill and a `.cursor/rules/graphify.mdc` rule for repository context. Exact destinations depend on whether you use a personal or project installation; the installer reports the files it writes.

For a repository-local setup, run this from the project root:

```bash
graphify install --project --platform cursor
```

## 2. Build the graph

Open your project in Cursor. Select the Graphify skill and enter:

```text
/graphify .
```

The assistant runs the Graphify workflow and writes `graphify-out/`. Code extraction runs locally; semantic extraction can use your assistant’s model for documents and media.

## 3. Ask with context

After the graph is built, ask:

> Use Graphify to explain the authentication flow. Cite the source files and distinguish explicit relationships from inferred ones.

You can also query from a terminal:

```bash
graphify query "authentication flow"
```

## Keep it current

```bash
uv tool upgrade graphifyy
graphify install --platform cursor
```

If the skill is missing, refresh the assistant and confirm that the registration was installed in the intended user or project scope. See [troubleshooting](/open-source/troubleshooting).
