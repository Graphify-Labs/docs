Graphify connects to GitHub through the Graphify GitHub App. You choose which repositories the app can see. Graphify indexes each one from its default branch, keeps the graph current on every push, and reviews pull requests against it.

## Connect repositories

<Steps>
  <Step title="Open Repositories">
    Sign in to [Graphify](https://app.graphify.com) and open **Repositories**.
  </Step>
  <Step title="Install the GitHub App">
    Click **Add GitHub repositories**. GitHub asks where to install the Graphify GitHub App and which repositories it can access. You need permission to install apps on that account or organization.
  </Step>
  <Step title="Wait for the first index">
    You return to **Repositories**. Each selected repository builds its first graph. When its status is **Indexed**, your agents can query it.
  </Step>
</Steps>

To add or remove repositories later, change the app's repository access on GitHub, or click **Add GitHub repositories** again.

## What the app does

- **Indexing.** A push to the default branch starts an index of that commit. Other branches do not change the graph. See [Repositories and builds](/platform/repositories).
- **Pull request reviews.** A review runs when a pull request is opened, reopened, or marked ready for review. New commits do not start a new review on their own. To review the current head, a repository owner, member, or collaborator comments `@graphify review`. See [Pull request reviews](/platform/reviews).
- **Formal verification.** Runs on each push to a pull request, separately from reviews. See [Formal verification](/platform/verification).
- **Feedback.** Reply `@graphify wrong <finding>`, `@graphify good <finding>`, or `@graphify suppress <rule>` to tune later reviews. See [Learning](/platform/learning).

Graphify reads repository contents to build the graph. Indexing tokens are short-lived and limited to the repositories you selected. They are never sent to your browser or stored. See [Security and data handling](/platform/support/security).

## Edge cases

- Pushes to other branches and branch deletions are ignored.
- A repository with indexing turned off ignores pushes.
- If you uninstall the app or remove a repository from it, reindex returns `409 provider_disconnected`. Reinstall the app, or remove the repository from Graphify.

See [Troubleshooting](/platform/support/troubleshooting#repository-connect-issues).

## Turn reviews off

In **Repositories**, open **Options** for the repository and switch **PR reviews** off. Indexing keeps running.
