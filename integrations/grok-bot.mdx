Add the Graphify plugin so Grok Bot can search the repositories indexed in your [Graphify](https://app.graphify.com?utm_source=docs&utm_medium=link&utm_campaign=integrations-grok-bot) workspace. You sign in once in the browser. There is no API key.

<AddPill href="https://x.ai/bot/plugin/90729235" label="Add to Grok Bot" logo="/images/logos/grok-bot-light.png" logoDark="/images/logos/grok-bot-dark.png" />

## Before you start

- A Graphify account. If you don't have one yet, you can create one for free while connecting. See [Plans and pricing](/platform/support/pricing).
- At least one repository with the status **Indexed**. The [quickstart](/platform/quickstart) connects GitHub and starts indexing. Indexing status is on [Repositories and builds](/platform/repositories).

## 1. Add the plugin

Open [Graphify for Grok Bot](https://x.ai/bot/plugin/90729235) and select **Add to Grok Bot**.

You can also do it from a chat. Ask your bot:

```text
Connect the Graphify plugin.
```

Grok Bot finds Graphify in its plugin search and shows a card to add it.

Don't have the app yet? [Download Grok Bot](https://x.ai/bot), then open the listing again.

### Or add the MCP server yourself

If you'd rather not use the plugin, ask Grok Bot to add a remote MCP server with this URL:

```text
https://api.graphify.com/mcp
```

You still sign in with OAuth. Use one route, not both, or every Graphify tool shows up twice.

## 2. Sign in

The first time Grok Bot uses Graphify, it asks you to sign in. Finish the Graphify sign-in in your browser and pick the workspace that holds your repositories.

## 3. Check the connection

In a chat, paste:

```text
List the repositories I can access in Graphify. If a tool fails, report the error instead of guessing.
```

Check that the list matches the workspace you chose when you signed in.

## 4. Ask a question

Name the repository and the symbol, file, or area you care about.

| You want to | Ask Grok Bot |
| --- | --- |
| Get your bearings in a repository | `Using Graphify, explain how requests reach the billing service in my-repo.` |
| Find who uses something | `In my-repo, who calls the function that validates a session token?` |
| Check a change before you make it | `What would break if I changed the billing module's public interface?` |
| Find the tests to run | `Which tests are linked to the checkout flow?` |
| Recall a team decision | `What did the team decide about retries in the payments service?` |

### Example from a real run

Tested with Grok Bot and the hosted Graphify MCP server on 26 Nov 2026, on the public [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) repository (indexed commit `02c27dc`).

```text
In Graphify-Labs/graphify, who calls the function that loads .graphifyignore?
```

Grok Bot used `graphify_find` to locate `_load_graphifyignore()` in `graphify/detect.py`, then `graphify_callers` to list its callers, and answered:

> `_load_graphifyignore()` has 21 callers. Five are in the package: `detect()` and `ignored_predicate()` in `graphify/detect.py`, `collect_files()` and `_xaml_csharp_class_nodes()` in `graphify/extract.py`, and `watch()` in `graphify/watch.py`. The other 16 are tests: 15 in `tests/test_detect.py` and 1 in `tests/test_extract.py`.

The counts change as the repository changes.

Answers are graph evidence from the files Graphify indexed. Open the source lines an answer cites before you rely on it. Some tools save workspace memory, so read what a tool will do before you approve it.

## Troubleshooting

| What you see | What to do |
| --- | --- |
| Grok Bot says Graphify needs sign-in | Ask it to connect Graphify again and finish the browser sign-in. |
| The tools return no repositories | The repository is not indexed yet, or it is in a different workspace. Check [Repositories and builds](/platform/repositories). |
| Answers look out of date | Graphify answers from the last indexed snapshot. Reindex the repository in Graphify. |

## FAQ

### Is there an official Graphify plugin for Grok Bot?

Yes. [Graphify for Grok Bot](https://x.ai/bot/plugin/90729235) is the official listing, published by Graphify. It connects Grok Bot to Graphify's hosted MCP server.

### Do I need an API key?

No. Grok Bot signs in with OAuth in your browser. There is no key to paste or store.

### Does it read files on my computer?

No. Graphify answers from repositories already indexed in your Graphify workspace.
