Connect [Hermes Agent](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp/) to Graphify in one of two ways. **Graphify (hosted)** uses Hermes's native remote MCP and OAuth support. No API key, wrapper, or local server is needed. **Graphify Local** installs the open-source skill. See [Graphify vs Local](/platform/graphify-vs-local) to choose.

<Tabs>
<Tab title="Graphify (hosted)">

## Before you start

- A [Graphify](https://app.graphify.com) account with a workspace and at least one repository that has finished indexing.
- A current Hermes release with native MCP OAuth support.

## 1. Add the server

Merge this entry into your active Hermes profile's `config.yaml`, normally `~/.hermes/config.yaml`. Keep your existing configuration and other MCP servers.

```yaml ~/.hermes/config.yaml
mcp_servers:
  graphify:
    url: https://api.graphify.com/mcp
    auth: oauth
```

## 2. Sign in

```bash
hermes mcp login graphify
```

Complete the authorization in your browser. Hermes stores and manages the OAuth credentials.

## 3. Choose tools

```bash
hermes mcp configure graphify
```

Pick the Graphify tools you want Hermes to use, then restart the Hermes session. Some tools write: they can record query trails, save or change memory, and switch the active workspace. Leave those off if you want read-only use.

## 4. Ask a question

Ask Hermes to list your Graphify workspaces and repositories, select a repository, and look up a function you know. Check that the file paths it returns match the repository.

## If something fails

- **Sign-in does not open.** Update Hermes to a release with MCP OAuth support, then run `hermes mcp login graphify` again.
- **No repositories.** Wait until the repository shows **Indexed** in **Repositories**, and check that you signed in to the right workspace.
- **An answer looks stale.** The graph follows the default branch. Results can lag behind a push until the next index finishes.

</Tab>
<Tab title="Graphify Local">

```bash
uv tool install graphifyy
graphify install --platform hermes
```

The installer copies the Graphify skill and adds a Graphify section to `AGENTS.md`, so Hermes checks the graph before it reads source. Add `--project` to install into the current repository instead of your profile. Then ask Hermes to map the repository with the Graphify skill.

</Tab>
