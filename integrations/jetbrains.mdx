The **Graphify MCP** plugin adds a tool window to your JetBrains IDE. From that window you copy a connection, paste it into JetBrains AI Assistant, and the assistant can search the repositories you have indexed in [Graphify Cloud](https://app.graphify.com).

The plugin does not read or upload your project files, and it stores no credentials of its own. There is no API key to paste. AI Assistant is a separate JetBrains product: this plugin does not include a chat model.

## Before you start

- A JetBrains IDE on the **2025.3** release. The published plugin declares platform build `253` through `253.*`, so it does not install on 2025.2 or on later releases.
- JetBrains AI Assistant, with access to MCP. Assistant access and your Graphify plan are separate.
- A repository indexed in your Graphify workspace. Sign in at [app.graphify.com](https://app.graphify.com), connect a repository, and wait for its status to reach **Indexed**. See [Repositories and builds](/platform/repositories).
- Node.js and npm on the IDE's PATH, if you use the OAuth bridge below. The direct connection does not need them.

## 1. Install the plugin

Install [Graphify MCP](https://plugins.jetbrains.com/plugin/34740-graphify-mcp) from the JetBrains Marketplace, or search for **Graphify MCP** by **Graphify Labs** in **Plugins**. The plugin id is `com.graphify.graphify-mcp`. Restart the IDE if it asks you to.

Open **View → Tool Windows → Graphify**.

## 2. Copy a configuration

In the tool window, choose a connection method and click **Copy configuration**.

<Tabs>
  <Tab title="OAuth bridge (STDIO)">
    Use this when AI Assistant cannot sign in to a remote MCP server on its own. The copied configuration runs the pinned `mcp-remote` package, which opens a browser for Graphify sign-in and stores those credentials on your machine.

    Node.js and npm must be on the IDE's PATH. Enabling the configuration is what downloads and runs the bridge.

    ```json
    {
      "mcpServers": {
        "graphify": {
          "command": "npx",
          "args": [
            "-y",
            "mcp-remote@0.14.3",
            "https://api.graphify.com/mcp",
            "--transport",
            "http-only"
          ]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Direct remote HTTP">
    Use this when your client can complete Graphify's sign-in itself. If sign-in is unavailable, switch to the OAuth bridge.

    ```json
    {
      "mcpServers": {
        "graphify": {
          "url": "https://api.graphify.com/mcp"
        }
      }
    }
    ```
  </Tab>
</Tabs>

The tool window shows the same JSON. Copy it from there if a later plugin release changes the text.

## 3. Add it to AI Assistant

Open **Settings → Tools → AI Assistant → Model Context Protocol (MCP)**. On macOS the menu is **Settings** or **Preferences**, then the same path. **Open Settings** in the tool window opens the IDE settings dialog; it does not jump straight to the MCP page.

Click **Add**, paste the copied JSON, and set the level to this project or to every project. Click **OK**, then **Apply**.

**Settings → Tools → MCP Server** is a different page. That one lets other applications use the IDE. It is not where this configuration goes.

## 4. Sign in and ask

Complete the Graphify sign-in in your browser when it opens. In the MCP settings, the server's status should show a connection. Then ask:

```text
List my Graphify repositories.
```

Pick a repository from the answer and ask about its code:

- `Find the implementation of this function.`
- `What calls this symbol, and which tests are linked to it?`
- `Find this function and show its callers.`

Results come from the repositories indexed in your workspace. Open the source an answer cites before you rely on it.

Some tools save repository notes or change the selected workspace. Read each tool request and approve it only when that is what you meant.

## Tool window

| Control | What it does |
| --- | --- |
| **Copy configuration** | Copies the JSON for the method you selected. |
| **Open Settings** | Opens the IDE settings dialog. |
| **Graphify workspace** | Opens your workspace in the browser. |
| **Setup documentation** | Opens the Graphify MCP setup guide. |

## If something fails

| What you see | What to do |
| --- | --- |
| The plugin will not install | The IDE is not on the 2025.3 release. The published plugin only accepts platform build 253. |
| `npx` or Node.js was not found | Install Node.js and npm, and make them available on the IDE's PATH. Restart the IDE after you do. |
| Direct HTTP cannot sign in | Switch the tool window to **OAuth bridge (STDIO)**, copy that configuration, and replace the server entry. |
| No repositories, or empty answers | The repository is not indexed yet, or it is in a different workspace. Check its status in [Repositories and builds](/platform/repositories). |
| The MCP page is missing | Check that AI Assistant is installed and that your JetBrains account can use it. |
| You cannot find where to paste | You are on **Settings → Tools → MCP Server**. Use **Settings → Tools → AI Assistant → Model Context Protocol (MCP)** instead. |
