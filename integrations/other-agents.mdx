<Tab title="Graphify (hosted)">

The [VS Code](/integrations/vscode), [JetBrains](/integrations/jetbrains), [ChatGPT, Codex, and Dots](/integrations/chatgpt), [OpenClaw](/integrations/openclaw), and [Vercel](/integrations/vercel) pages are install packages for one product. They are not the only way to use Graphify.

Any coding assistant or IDE that can add a remote MCP server can use the same hosted server. That includes Antigravity, Windsurf, Cline, Continue, Zed, and clients that are not listed yet.

The server is `https://api.graphify.com/mcp`. It uses Streamable HTTP. The first connection signs you in with OAuth. There is no API key to paste.

## Copy a setup prompt

The **Copy setup prompt** button on [graphify.com](https://graphify.com) copies this same text. Paste it into the assistant you want to connect. The assistant reads the current guide, keeps your existing MCP servers, and stops so you can sign in yourself.

```text
Help me connect Graphify (https://graphify.com) to this assistant so you can answer questions using my codebase's knowledge graph.

Read the current setup guide at https://docs.graphify.com/integrations/overview first. Use the instructions for this client and preserve any existing MCP servers or configuration.

For Graphify, the Streamable HTTP MCP endpoint is https://api.graphify.com/mcp. Guide me through adding Graphify and completing its OAuth sign-in. I need a Graphify account, access to a workspace, and an indexed repository; if those are missing, help me get started at https://app.graphify.com. Let me complete sign-in and authorization myself.

If this client cannot configure a connection directly, show me the manual steps and any plan or workspace-admin requirements. If I want a local graph instead, follow https://docs.graphify.com/open-source/mcp-server. Do not claim the connection succeeded until it has been verified.

After connecting, list my available workspaces and indexed repositories, ask which repository to use, and answer one architecture question using graph evidence and source locations.
```

## Before you start

- A Graphify account, access to a workspace, and a repository whose status is **Indexed**. Start at [app.graphify.com](https://app.graphify.com). See [Repositories and builds](/platform/repositories).
- An assistant that can add an HTTP or Streamable HTTP MCP server.

## 1. Add the server

Name the server `graphify` and set the URL to `https://api.graphify.com/mcp`. Leave every other MCP server in place.

If the assistant can add the server, let it. If it cannot, open its MCP settings and add the URL by hand. The file or command for a named client is on the [Graphify MCP connection guide](https://graphify.com/mcp).

Use the dedicated page when the client already has one:

- [Graphify MCP for VS Code](/integrations/vscode)
- [Graphify MCP for JetBrains](/integrations/jetbrains)
- [ChatGPT, Codex, and Dots](/integrations/chatgpt)
- [Graphify MCP for OpenClaw](/integrations/openclaw)
- [Graphify MCP for Vercel](/integrations/vercel)

## 2. Sign in

Start the server. Your browser opens so you can sign in to Graphify and grant access. Choose the workspace that holds the repository you want to query. Complete that sign-in yourself.

The connection is working when the assistant lists Graphify's tools. Until then, it is not connected.

## 3. Ask a question

Ask the assistant to list your workspaces and indexed repositories, then name the repository to use. Ask one question about how the code is structured.

Answers are graph evidence from the files Graphify indexed, with source locations. Open those lines before you rely on the answer.

Some tools can save repository memory or change the selected workspace. Approve a tool only when that is what you meant.

## Troubleshooting

| What you see | What to do |
| --- | --- |
| The repository is missing | It is not indexed yet, or it is in another workspace. Check its status in [Repositories and builds](/platform/repositories). |
| The assistant asks for an API key | This server uses OAuth. The URL is `https://api.graphify.com/mcp`. |
| The tools are the ten local ones | That connection reads a graph on your machine. This page uses the hosted server. See the [MCP tool reference](/open-source/features/mcp-tools). |
| The same tools appear twice | A dedicated plugin and a manual server are both configured. Keep one. |

## 1. Install and register

Install the package once, then select your platform:

```bash
uv tool install graphifyy
graphify install --platform opencode
```

| Assistant | Platform value |
| --- | --- |
| OpenCode | `opencode` |
| Kilo Code | `kilo` |
| CodeBuddy | `codebuddy` |
| Aider | `aider` |
| Amp | `amp` |
| OpenClaw | `claw` |
| Factory Droid | `droid` |
| Trae | `trae` |
| Trae CN | `trae-cn` |
| Hermes | `hermes` |
| Kiro | `kiro` |
| Pi | `pi` |
| Devin CLI | `devin` |
| Google Antigravity | `antigravity` |
| Shared agent skill convention | `agents` |

Some integrations use skills plus instructions; others also install native rules or hooks. Review the files reported by the installer. Use the assistant’s skill picker or ask it directly to use Graphify if it has no slash-command UI.

The OpenClaw row installs the local skill. To query repositories indexed in Graphify, use [Graphify MCP for OpenClaw](/integrations/openclaw).

## Use any MCP client

An assistant does not need a dedicated skill installer to read an existing graph. If it supports MCP, connect the [Graphify MCP server](/open-source/mcp-server). Build the graph separately with the CLI or a supported assistant.
