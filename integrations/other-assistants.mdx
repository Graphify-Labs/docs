Install the package once, then select your platform:

```bash
uv tool install graphifyy
graphify install --platform opencode
```

| Assistant | Platform value |
| --- | --- |
| OpenCode | `opencode` |
| Kilo Code | `kilo` |
| CodeBuddy | `codebuddy` |
| Aider | `aider` |
| Amp | `amp` |
| OpenClaw | `claw` |
| Factory Droid | `droid` |
| Trae | `trae` |
| Trae CN | `trae-cn` |
| Hermes | `hermes` |
| Kiro | `kiro` |
| Pi | `pi` |
| Devin CLI | `devin` |
| Google Antigravity | `antigravity` |
| Shared agent skill convention | `agents` |

Some integrations use skills plus instructions; others also install native rules or hooks. Review the files reported by the installer. Use the assistant’s skill picker or ask it directly to use Graphify if it has no slash-command UI.

The OpenClaw row installs the local skill. To query repositories indexed in Graphify Cloud, use [Graphify MCP for OpenClaw](/integrations/openclaw).

## Any MCP client

An assistant does not need a dedicated skill installer to read an existing graph. If it supports MCP, connect the [Graphify MCP server](/mcp/overview). Build the graph separately with the CLI or a supported assistant.
