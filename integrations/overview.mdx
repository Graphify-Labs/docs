Graphify is shared codebase context for agents and the people who work with them: a code graph, a wiki, memory, and pull request reviews. Connect [Claude Code](/integrations/claude-code), [Cursor](/integrations/cursor), [VS Code](/integrations/vscode), [Codex](/integrations/codex), and the other assistants below to the hosted MCP server, or install the Graphify CLI skill on a graph you build locally.

**Graphify** answers from repositories you have indexed, through `https://api.graphify.com/mcp`, with no local build. **Graphify CLI** installs the open-source `graphifyy` skill and builds the graph on your machine. See [Graphify vs Graphify CLI](/platform/graphify-vs-local) to choose.

## Graphify CLI

The package is `graphifyy`. The command is `graphify`. `graphify install` writes the skill into the assistant you name.

### The common workflow

```bash
uv tool install --python 3.12 graphifyy
graphify install --platform cursor
```

Replace `cursor` with the installer platform for your assistant. Restart or refresh the assistant if it does not discover the new skill immediately, then ask it to map the current repository with Graphify.

Skill invocation differs by client. Slash commands are common; Codex also exposes skills through the `$` picker. If a client does not show slash commands, explicitly ask it to use the installed Graphify skill.

### Project or personal installation

The default registration is personal. Add `--project` for repository-local registration where supported. This makes the instructions reviewable in version control and lets a team share the setup.

The installer adds platform-specific files and may install hooks or instructions that suggest querying the graph before reading source. It does not grant your assistant new permissions.


### Local MCP server

The [local MCP server](/open-source/mcp-server) exposes a graph that already exists on your machine as MCP tools. Use it with the skill or on its own.

## FAQ

### Does Graphify work with Claude Code, Cursor, or VS Code?

Yes. See [Claude Code](/integrations/claude-code), [Cursor](/integrations/cursor), and [VS Code and GitHub Copilot](/integrations/vscode). The table above lists every assistant on this page, including Codex, Gemini CLI, JetBrains, ChatGPT, OpenClaw, and Hermes.

### Do I need Graphify CLI if I use hosted Graphify?

No. Hosted Graphify is enough when you connect your agent over MCP and have an indexed repository. Use Graphify CLI when you want an offline or on-machine graph.

### What is always-on context?

It is what `graphify install` writes so the agent checks the graph before reading source, without being asked. Hooks never grant the agent new permissions.
