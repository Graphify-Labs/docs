## Graphify

You need a Graphify account. If you don't have one yet, you can create one for free while connecting. The Free plan needs no card. See [Plans and pricing](/platform/support/pricing). Wait until a repository's status is **Indexed**, then pick your agent. Each page signs you in with OAuth; no API key is needed.

## FAQ

### Does Graphify work with Claude Code, Cursor, or VS Code?

Yes. See [Claude Code](/integrations/claude-code), [Cursor](/integrations/cursor), and [VS Code and GitHub Copilot](/integrations/vscode). The table above lists every assistant on this page, including Codex, Gemini CLI, JetBrains, ChatGPT, Grok Bot, OpenClaw, Hermes, and OpenCode.

### Do I need Graphify CLI if I use hosted Graphify?

No. These pages are enough when a repository is indexed. Use [Graphify CLI](/open-source/agents/overview) when you want the graph on your machine.
