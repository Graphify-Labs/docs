Two public MCP servers answer questions about Graphify. The docs server searches these pages. The website server searches public pages on [graphify.com](https://graphify.com).

Questions about your code go to [Graphify MCP](/platform/graphify-mcp) at `https://api.graphify.com/mcp`, or to the [local MCP server](/open-source/mcp-server) when the graph is on your machine.

The Cursor and VS Code entries in the page menu install Graphify MCP. Use the steps below for the two documentation servers.

## Docs pages

```text
https://docs.graphify.com/mcp
```

Use this server when the answer is on docs.graphify.com: install steps, CLI flags, the console, and concepts.

| Tool | What you get |
| --- | --- |
| `search_graphify` | Titles and links for matching docs pages. |
| `query_docs_filesystem_graphify` | The text of a published docs page. The lookup stays inside those pages and does not run on your computer. |
| `submit_feedback` | A note that a docs page is wrong, outdated, or unclear. You send the page path and the note. The tool does not change the page. |

The server also exposes a skill resource named `graphify`. The text is the same as [skill.md](https://docs.graphify.com/skill.md): how to connect an agent to `https://api.graphify.com/mcp`.

## Website pages

```text
https://graphify.com/api/mcp
```

Use this server for public pages on graphify.com. It has one tool, `search_graphify_docs`. Each hit is a title, a URL, and a snippet.

The tool describes its index as quickstart, concepts, per-language and per-assistant guides, comparisons, glossary, FAQ, and blog. Results are pages on graphify.com. Searches returned glossary entries, FAQ answers, blog posts, and the pricing page.

## Add the docs server

Name the server `graphify-docs`. Leave an existing `graphify` entry in place. `graphify` is the product server.

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http graphify-docs https://docs.graphify.com/mcp
    ```
  </Tab>
  <Tab title="Cursor">
    ```json ~/.cursor/mcp.json
    {
      "mcpServers": {
        "graphify-docs": {
          "url": "https://docs.graphify.com/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="VS Code">
    Run **MCP: Add Server** from the Command Palette, choose **HTTP**, enter `https://docs.graphify.com/mcp`, and name it `graphify-docs`. Or add `.vscode/mcp.json`:

    ```json .vscode/mcp.json
    {
      "servers": {
        "graphify-docs": {
          "type": "http",
          "url": "https://docs.graphify.com/mcp"
        }
      }
    }
    ```

    VS Code uses `servers` in this file.
  </Tab>
  <Tab title="Codex">
    ```bash
    codex mcp add graphify-docs --url https://docs.graphify.com/mcp
    ```
  </Tab>
</Tabs>

- How do I run a code-only extraction?
- What is the difference between query, path, and explain?

- What do EXTRACTED, INFERRED, and AMBIGUOUS mean?
- What is a code graph?
