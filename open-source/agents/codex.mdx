This page installs the open-source skill. Codex builds the graph from the project on your machine. To query a repository already indexed in Graphify, use [Graphify for Codex](/integrations/codex).

## 1. Install and register

```bash
uv tool install --python 3.12 graphifyy
graphify install --platform codex
```

The installer writes the Graphify skill and `AGENTS.md` instructions. It also supports Codex hook integration, and it reports the files it writes.

For a repository-local setup, run this from the project root:

```bash
graphify install --project --platform codex
```

## 2. Build the graph

Open the project in Codex. Select the Graphify skill and enter:

```text
$graphify map the current repository
```

In the Codex desktop app, local skills live in the `@` menu, not the `/` menu. Type `@graphify`, select the skill, then add your request.

The assistant runs the workflow and writes `graphify-out/`. Code extraction runs locally. Semantic extraction can use your assistant's model for documents and media.

## 3. Ask with context

Once the graph is built, ask Codex to answer from it and cite the source files:

> Use Graphify to explain the authentication flow. Cite the source files and distinguish explicit relationships from inferred ones.

You can also query from a terminal:

```bash
graphify query "authentication flow"
```

## Keep it current

```bash
uv tool upgrade graphifyy
graphify install --platform codex
```

If the skill is missing, refresh Codex and confirm the install is in the scope you intended. See [troubleshooting](/open-source/troubleshooting).

To call the same graph as tools, connect the [local MCP server](/open-source/mcp-server).
