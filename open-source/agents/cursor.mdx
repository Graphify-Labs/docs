This page installs the open-source skill. Cursor builds the graph from the project on your machine. To query a repository already indexed in Graphify, use [Graphify for Cursor](/integrations/cursor).

## How do I set up Graphify CLI in Cursor?

Run `uv tool install graphifyy`, then `graphify install --platform cursor`, and enter `/graphify .` in Cursor. Cursor builds the graph in `graphify-out/` on your machine and can query it from then on.

## 1. Install and register

```bash
uv tool install graphifyy
graphify install --platform cursor
```

The installer writes the skill and a `.cursor/rules/graphify.mdc` rule. It reports the files it writes. Destinations depend on whether the install is for your user or for one project.

For a repository-local setup, run this from the project root:

```bash
graphify install --project --platform cursor
```

## 2. Build the graph

Open the project in Cursor. Select the Graphify skill and enter:

```text
/graphify .
```

The assistant runs the workflow and writes `graphify-out/`. Code extraction runs locally. Semantic extraction can use your assistant's model for documents and media.

## 3. Ask with context

Once the graph is built, ask Cursor to answer from it and cite the source files:

> Use Graphify to explain the authentication flow. Cite the source files and distinguish explicit relationships from inferred ones.

You can also query from a terminal:

```bash
graphify query "authentication flow"
```

## Keep it current

```bash
uv tool upgrade graphifyy
graphify install --platform cursor
```

If the skill is missing, refresh Cursor and confirm the install is in the scope you intended. See [troubleshooting](/open-source/troubleshooting).

To call the same graph as tools, connect the [local MCP server](/open-source/mcp-server).
