This page installs the open-source skill. Gemini CLI builds the graph from the project on your machine. To query a repository already indexed in Graphify, use [Graphify for Gemini CLI](/integrations/gemini-cli).

## 1. Install and register

```bash
uv tool install --python 3.12 graphifyy
graphify install --platform gemini
```

The installer uses `GEMINI.md` instructions and a BeforeTool hook to suggest graph queries. It reports the files it writes.

For a repository-local setup, run this from the project root:

```bash
graphify install --project --platform gemini
```

## 2. Build the graph

Open the project in Gemini CLI. Select the Graphify skill and enter:

```text
/graphify .
```

The assistant runs the workflow and writes `graphify-out/`. Code extraction runs locally. Semantic extraction can use your assistant's model for documents and media.

## 3. Ask with context

After the graph is built, ask:

> Use Graphify to explain the authentication flow. Cite the source files and distinguish explicit relationships from inferred ones.

You can also query from a terminal:

```bash
graphify query "authentication flow"
```

## Keep it current

```bash
uv tool upgrade graphifyy
graphify install --platform gemini
```

If the skill is missing, refresh Gemini CLI and confirm the install is in the scope you intended. See [troubleshooting](/open-source/troubleshooting).

To call the same graph as tools, connect the [local MCP server](/open-source/mcp-server).
