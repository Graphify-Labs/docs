This page installs the open-source skill. Hermes builds the graph from the project on your machine. To query a repository already indexed in Graphify, use [Graphify for Hermes](/integrations/hermes).

## How do I set up Graphify CLI in Hermes?

Run `uv tool install --python 3.12 graphifyy`, then `graphify install --platform hermes`, and ask Hermes to map the repository with the Graphify skill. Hermes builds the graph on your machine and checks it before it reads source.

```bash
uv tool install --python 3.12 graphifyy
graphify install --platform hermes
```

The installer copies the Graphify skill and adds a Graphify section to `AGENTS.md`, so Hermes checks the graph before it reads source. Add `--project` to install into the current repository instead of your profile. Then ask Hermes to map the repository with the Graphify skill.

If the skill is missing, refresh Hermes and confirm the install is in the scope you intended. See [troubleshooting](/open-source/troubleshooting).
