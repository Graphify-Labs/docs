Install the package once, then name the agent. To query a repository already indexed in Graphify, use [Other MCP clients](/integrations/other-agents).

```bash
uv tool install --python 3.12 graphifyy
graphify install --platform opencode
```

| Assistant | Platform value |
| --- | --- |
| OpenCode | `opencode` |
| Kilo Code | `kilo` |
| CodeBuddy | `codebuddy` |
| Aider | `aider` |
| Amp | `amp` |
| OpenClaw | `claw` |
| Factory Droid | `droid` |
| Trae | `trae` |
| Trae CN | `trae-cn` |
| Hermes | `hermes` |
| Kiro | `kiro` |
| Pi | `pi` |
| Devin CLI and Devin Desktop (formerly Windsurf) | `devin` |
| Google Antigravity | `antigravity` |
| Kimi Code | `kimi` |
| Shared agent skill convention | `agents` |

For example, run `graphify install --platform antigravity` for Google Antigravity.

Some installs write a skill and instructions. Others also write native rules or hooks. Read the files the installer reports. If the agent has no slash-command menu, ask it to use the Graphify skill.

The OpenCode row writes `AGENTS.md` and a `tool.execute.before` plugin. You can also run `graphify opencode install`. Hosted OpenCode setup stays on the [OpenCode cookbook](/cookbooks/opencode).

The OpenClaw row installs the local skill. To query repositories indexed in Graphify, use [Graphify for OpenClaw](/integrations/openclaw).

## Pi and Oh My Pi

Pi has no `PreToolUse` hook, so Graphify CLI ships a native Pi extension. It runs the same graph check before Pi's `read`, `grep`, `find`, and search-style `bash` calls. It needs Pi 0.58.4 or newer, and Graphify installed with `uv tool install --python 3.12 graphifyy` or `pipx install graphifyy`, not `uvx`.

```bash
graphify install --platform pi
graphify pi guard install
```

Restart Pi after you install or upgrade. Remove the extension with `graphify pi guard uninstall`.

The same package also loads in [Oh My Pi](https://github.com/can1357/oh-my-pi):

```bash
omp plugin install "$(graphify pi guard path)"
```

The registered path includes your Python version and virtual environment. If either changes, run `graphify pi guard install` again.

## Use any MCP client

An assistant does not need a skill install to read a graph that already exists. If it supports MCP, connect the [local MCP server](/open-source/mcp-server). Build the graph first with the CLI or a supported assistant.
