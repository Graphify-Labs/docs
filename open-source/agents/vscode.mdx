Copilot CLI and Copilot Chat in VS Code use different installs. Pick the one you run. To query a repository already indexed in Graphify, install the [Graphify MCP extension](/integrations/vscode).

## 1. Install and register

**Copilot CLI**

```bash
uv tool install --python 3.12 graphifyy
graphify install --platform copilot
```

The installer registers the Graphify skill for Copilot CLI. Ask the assistant to use that skill to map the repository, then query the saved graph.

**VS Code**

```bash
uv tool install --python 3.12 graphifyy
graphify vscode install
```

This uses the VS Code integration the installer supports. You can also connect the [local MCP server](/open-source/mcp-server) for structured tool calls.

## 2. Check the graph

```bash
graphify query "application entry points"
```

If `graphify-out/graph.json` does not exist yet, follow the [quickstart](/open-source/quickstart) or build with `graphify extract . --code-only`.
