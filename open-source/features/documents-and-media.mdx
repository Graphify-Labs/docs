Code explains what a system does. Design docs, papers, meeting recordings, and specs explain why. Graphify Local puts both in one graph, so your agent can go from a function to the ADR that justified it. Code is parsed locally with no model. Everything else goes through **semantic extraction**: a model you choose reads each chunk and returns the concepts and relationships in it.

<Note>
**Use this when** your repository has a `docs/` folder, research PDFs, or recorded walkthroughs that your agent should know about. For a code-only graph with no API key, use `graphify extract . --code-only`.
</Note>

## What Graphify reads

| Kind | Extensions | Needs |
| --- | --- | --- |
| Docs | `.md` `.mdx` `.qmd` `.txt` `.rst` `.html` `.skill` `.j2` `.jinja` `.jinja2` | A model backend |
| Papers | `.pdf` | `graphifyy[pdf]` |
| Office | `.docx` `.xlsx` | `graphifyy[office]` |
| Images | `.png` `.jpg` `.jpeg` `.gif` `.webp` `.svg` | A model backend |
| Video and audio | `.mp4` `.mov` `.webm` `.mkv` `.avi` `.m4v` `.mp3` `.wav` `.m4a` `.ogg` | `graphifyy[video]` |
| Google Workspace | `.gdoc` `.gsheet` `.gslides` shortcuts | The `gws` CLI and `--google-workspace` |

Install every optional reader at once with `pip install "graphifyy[all]"`.

## How it works

<Steps>
  <Step title="Detect">
    Files are sorted by kind. Video and audio are transcribed locally with Whisper, then treated as text. Google Workspace shortcuts are exported to Markdown with `gws`.
  </Step>
  <Step title="Chunk">
    Text is split into chunks of up to 60,000 tokens (`--token-budget`).
  </Step>
  <Step title="Extract">
    Your model returns nodes and edges for each chunk. Up to 4 chunks run at once (`--max-concurrency`).
  </Step>
  <Step title="Merge">
    Concepts are deduplicated and joined to the code graph, then clustered with everything else.
  </Step>
</Steps>

Results are cached by file content, so unchanged documents are never sent to the model twice.

## See it in action

<CodeGroup>
```bash Whole folder
graphify extract . --backend claude
```

```bash Code only, no key
graphify extract . --code-only
```

```bash Add a URL
graphify add https://arxiv.org/abs/1706.03762 --author "Vaswani et al."
```
</CodeGroup>

`graphify add` saves the page to `./raw` and updates the graph. It recognises arXiv, GitHub, YouTube, X posts, PDFs, and images by URL, and treats anything else as a web page. `--author` and `--contributor` tag who wrote and who added the source.

## Configure

<Tabs>
  <Tab title="Extraction depth">
    ```bash
    graphify extract . --mode deep
    ```
    `--mode deep` asks the model for more `INFERRED` relationships. It costs more tokens.
  </Tab>
  <Tab title="Local models">
    ```bash
    graphify extract . --backend ollama --max-concurrency 1
    ```
    Use one chunk at a time for local models.
  </Tab>
  <Tab title="Transcription">
    ```bash
    export GRAPHIFY_WHISPER_MODEL=small
    export GRAPHIFY_WHISPER_PROMPT="Graphify, Leiden, tree-sitter"
    ```
    The default Whisper model is `base`. A prompt with your project's terms improves spelling of names.
  </Tab>
  <Tab title="Google Workspace">
    ```bash
    graphify extract . --google-workspace
    ```
    Or set `GRAPHIFY_GOOGLE_WORKSPACE=1`. Requires the `gws` CLI, signed in.
  </Tab>
</Tabs>

## Corpus size

Graphify checks the size of your corpus before extraction. Under about 50,000 words, it tells you a graph may not be worth it; over 500,000 words or 500 files, it warns about token cost. Use a `.graphifyignore` file to leave out generated docs and archives.

## Verify and troubleshoot

| Symptom | Fix |
| --- | --- |
| PDFs or Office files skipped | Install the extra: `pip install "graphifyy[pdf]"` or `"graphifyy[office]"`. |
| No doc nodes at all | No backend was found. Set an API key or pass `--backend`. |
| Video skipped | Install `graphifyy[video]` (Python 3.11 or later). |
| `.gdoc` files appear empty | Pass `--google-workspace` and sign in to `gws`. |
| Local model times out | Lower `--token-budget` and use `--max-concurrency 1`. |

<AccordionGroup>
  <Accordion title="Is my content sent anywhere?">
    Code never is. Docs, images, and transcripts go only to the model backend you configured. With Ollama, nothing leaves your machine.
  </Accordion>
  <Accordion title="Can I re-run extraction without paying again?">
    Yes. Cached chunks are reused. `--force` (or `GRAPHIFY_FORCE=1`) ignores the cache.
  </Accordion>
</AccordionGroup>

## See what a code-only run skips

These examples come from a code-only graph of the open-source [httpx](https://github.com/encode/httpx) repository, built with Graphify Local 0.9.97. Your counts will differ.

```text
[graphify extract] --code-only: skipping 41 non-code file(s) (31 docs, 0 papers, 10 images) — no LLM extraction
```

Leave out `--code-only` and set a backend key to include those documents and images.

## Extras by input

| Input | Extensions | Extra |
| --- | --- | --- |
| PDF | `.pdf` | `pdf` (`pypdf`, `markdownify`) |
| Word and Excel | `.docx` `.xlsx` | `office` (`python-docx`, `openpyxl`) |
| Google Workspace | `.gdoc` `.gsheet` `.gslides` | `google` (`openpyxl`), plus the `gws` CLI and `--google-workspace` |
| Video and audio | `.mp4` `.mov` `.mkv` `.webm` `.avi` `.m4v` `.mp3` `.wav` `.m4a` `.ogg` | `video` (`faster-whisper`, `yt-dlp`) |
| Images | `.png` `.jpg` `.jpeg` `.gif` `.webp` `.svg` | A backend that supports images |

## FAQ

**Can I add a web page?** Yes. `graphify add <url>` saves it to `./raw` and updates the graph. Pass `--author` and `--contributor` to tag it.
