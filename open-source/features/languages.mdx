Graphify supports a growing set of languages and input formats. Parser coverage varies by construct, and specialized extractors may require an optional package. The [package manifest](https://github.com/Graphify-Labs/graphify/blob/v8/pyproject.toml) lists the current dependencies.

## Code and configuration

| Input | Examples | Notes |
| --- | --- | --- |
| General-purpose code | Python, JavaScript, TypeScript, Go, Rust, Java, C, C++, Ruby, C#, Kotlin, Scala, PHP, Swift, Lua, Zig | Local structural extraction; framework and dynamic-language coverage varies. |
| Additional code | Elixir, Julia, Groovy, PowerShell, Fortran, Verilog, Bash | See the repository’s input table for extensions. |
| Web component files | Vue, Svelte, Astro, JSX, TSX | Extraction depends on the file and supported embedded syntax. |
| SQL | Tables, views, foreign keys, joins | Install the `sql` extra. |
| Terraform / HCL | `.tf`, `.tfvars`, `.hcl` | Install `terraform`; the graph describes source configuration, not a Terraform plan. |
| OCaml / Common Lisp | `.ml`, `.mli`, `.lisp`, `.cl` | Install `ocaml` or `commonlisp`. |
| Robot Framework | `.robot`, `.resource` | Install `robot`; uses the official Robot parser. |
| Salesforce Apex | `.cls`, `.trigger` | Regex-based extraction. |
| Package and MCP manifests | `pyproject.toml`, `go.mod`, `pom.xml`, MCP JSON files | Packages, dependency edges, and server configuration context. |

## Documents and media

| Input | Setup |
| --- | --- |
| Markdown, MDX, text, HTML, reStructuredText | A semantic backend for rich concept extraction. |
| PDFs | `pdf` extra. |
| Word and Excel | `office` extra. |
| Google Workspace shortcuts | Authenticated `gws` CLI and explicit `--google-workspace`; `google` extra for Sheets. |
| Images | A backend with the required image capability. |
| Video and audio | `video` extra; transcription and semantic processing are separate steps. |

## Keep the first scan focused

Start with a repository or one documentation folder. Exclude build outputs and dependencies using [ignore rules](/open-source/features/incremental-updates). Add media only when it contributes useful context; transcription and semantic extraction have different resource requirements from a code-only scan.

## Check what a scan picked up

Every extraction prints what it found and what it skipped. These examples come from a code-only graph of the open-source [httpx](https://github.com/encode/httpx) repository, built with Graphify Local 0.9.97. Your counts will differ.

```text
$ graphify extract . --code-only
[graphify extract] --code-only: skipping 41 non-code file(s) (31 docs, 0 papers, 10 images) — no LLM extraction
[graphify extract] found 78 code, 0 docs, 0 papers, 0 images
[graphify extract] 5 file(s) not classified (no supported extension or shebang), skipped: .gitignore, .netrc-nopassword, CNAME, custom.css, py.typed
[graphify extract] 1 file(s) skipped as potentially sensitive (rename or move if wrongly flagged): .netrc
  warning: 4 code file(s) yielded no symbols (0.00 MB) — a data file, or source this extractor models no symbols for: httpx/__version__.py, httpx/_transports/__init__.py, pyproject.toml, tests/common.py
```

Read those lines as follows:

- **Not classified** means the file has no supported extension and no shebang, so Graphify skips it.
- **Potentially sensitive** files are always skipped. The rules cover `.env` files, keys and certificates (`.pem`, `.key`, `.p12` and others), SSH private keys, and credential dotfiles such as `.netrc`, `.npmrc`, `.pypirc` and `.git-credentials`.
- **Yielded no symbols** is a warning, not an error. Package `__init__.py` files and data files often contain nothing to model.

## FAQ

**Does `--code-only` need an API key?** No. Code goes through local AST extraction. Documents, papers and images are skipped.

**A file in my language was skipped.** Check its extension against the table. If it's a script without an extension, add a shebang line.

**Why did `pyproject.toml` yield no symbols?** It's classified as code but contributes package metadata rather than functions or classes.
