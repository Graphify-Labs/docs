<Tip>
Don't want to install anything? Start with the [Graphify quickstart](/platform/quickstart). Graphify indexes your GitHub repositories in the browser and hosts the graph for you, so there's nothing to deploy.
</Tip>

## Prerequisites

| Requirement | Check |
| --- | --- |
| Python 3.10 or later | uv installs this. With pip or a virtual environment, `python3 --version` |
| uv or pipx | `uv --version` or `pipx --version` |
| A coding assistant, for the skill workflow | [Choose an integration](/integrations/overview) |

The standalone CLI works without an assistant. Code-only extraction does not require an API key.

## Get uv

uv downloads Python 3.10 or later for Graphify. Install uv for your system, open a new terminal, and run `uv --version`.

<CodeGroup>
```bash macOS
brew install uv
```
```bash Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
```
```powershell Windows
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```
</CodeGroup>

The macOS command is Homebrew. The Linux and Windows commands are uv's own installers. Other methods, including MacPorts, are in the [uv installation guide](https://docs.astral.sh/uv/getting-started/installation/).

## Install the package

<Tabs>
  <Tab title="uv">
    Recommended. uv downloads Python 3.10 or later if you need it and keeps Graphify in its own tool environment.

    ```bash
    uv tool install graphifyy
    ```
  </Tab>
  <Tab title="pipx">
    Use pipx if you already install command line tools with it. pipx also manages the environment for you.

    ```bash
    pipx install graphifyy
    ```
  </Tab>
  <Tab title="Python environment">
    Use a virtual environment if you already manage Python yourself and want Graphify inside a project.

    ```bash
    python3 -m venv .venv
    .venv/bin/python -m pip install graphifyy
    ```

    On Windows, a virtual environment’s executable is `.venv\Scripts\python.exe`.
  </Tab>
</Tabs>

<Note>The official PyPI package is `graphifyy`. Other similarly named packages are not the Graphify Labs package.</Note>

The package is `graphifyy`. The command you run is `graphify`. If your shell cannot find `graphify` after install, see [Command not found](#command-not-found).

## Register the skill

```bash
graphify install
graphify install --platform codex
```

The first command detects an assistant. The second targets one explicitly. Run the specific command for each assistant you use.

Open the assistant in a repository and send `/graphify .`. That message builds the graph for the folder. Follow [Your first knowledge graph](/open-source/quickstart) to read the output and ask a question.

Use `--project` when you want the registration committed with a repository:

```bash
graphify install --project --platform codex
```

Read the installer’s list of files before committing them. Project and user registrations live in different locations.

## Optional capabilities

Install only the extras your workflow needs. Quote bracketed names in zsh.

| Capability | uv installation |
| --- | --- |
| MCP server | `uv tool install "graphifyy[mcp]"` |
| File watching | `uv tool install "graphifyy[watch]"` |
| PDFs | `uv tool install "graphifyy[pdf]"` |
| SQL parsing | `uv tool install "graphifyy[sql]"` |
| Terraform | `uv tool install "graphifyy[terraform]"` |
| Office documents | `uv tool install "graphifyy[office]"` |
| Local Ollama backend | `uv tool install "graphifyy[ollama]"` |
| Leiden clustering | `uv tool install "graphifyy[leiden]"` |

Combine extras, for example `uv tool install "graphifyy[mcp,watch]"`. If uv reports an existing installation, use its `--reinstall` option to replace that tool environment with the requested extras.

## Upgrade

```bash
uv tool upgrade graphifyy
graphify install --platform codex
```

Re-run registration for the assistants you use so their skill files match the package. If you installed git hooks, run `graphify hook install` again after moving or reinstalling the Python environment.

## Command not found

If `graphify` is not on your `PATH` after `uv tool install graphifyy`, run:

```bash
uv tool update-shell
```

Then open a new terminal. With pipx, run `pipx ensurepath`. If an MCP client cannot find Graphify, use an absolute executable path in its configuration. More install failures are in [Troubleshooting](/open-source/troubleshooting).

## Remove a registration

```bash
graphify uninstall --project --platform codex
```

`graphify uninstall` removes user registrations across platforms. The optional `--purge` flag also deletes `graphify-out/`; omit it to preserve your graph. Without `--project`, `graphify uninstall` also removes the git hooks and the merge driver, and `graphify hook uninstall` removes only those ([Turn off or remove the hooks](/open-source/keep-the-graph-fresh#turn-off-or-remove-the-hooks)).
