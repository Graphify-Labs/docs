The fastest way to use open-source Graphify is as a skill inside your coding agent. You install it once, type `/graphify .`, and the agent builds the graph and reads `GRAPH_REPORT.md` before it answers questions about your code.

<Note>
**Use the skill when** you work in Claude Code, Codex, Cursor, Gemini CLI, or another agent that supports skills, and you want the agent to drive extraction for you. If you only want terminal commands, follow the [CLI quickstart](/open-source/cli-quickstart).
</Note>

## Before you start

- Python 3.10 or later
- A coding agent that `graphify install` supports (Claude Code is the default)

## Build your first graph

<Steps>
  <Step title="Install the package">
    <CodeGroup>
    ```bash uv
    uv tool install graphifyy
    ```

    ```bash pipx
    pipx install graphifyy
    ```

    ```bash pip
    pip install graphifyy
    ```
    </CodeGroup>

    The package is `graphifyy` (two y's). It installs the `graphify` and `graphify-mcp` commands.
  </Step>
  <Step title="Install the skill">
    ```bash
    graphify install
    ```

    With no flag, this targets Claude Code. It copies the skill to `~/.claude/skills/graphify/SKILL.md` and registers it in `~/.claude/CLAUDE.md`. For another agent, pass `--platform`, for example `graphify install --platform codex`.
  </Step>
  <Step title="Run it in your agent">
    Open your agent in the repository and type:

    ```text
    /graphify .
    ```

    The agent runs detection, extraction, and clustering, then summarises the report. Code is parsed locally. Documents, papers, and images go through the agent's own model.
  </Step>
  <Step title="Ask a question">
    ```text
    /graphify query "how does authentication reach the database"
    ```

    The skill traverses the graph and returns only the nodes and edges that answer the question, trimmed to a token budget.
  </Step>
</Steps>

## What changes in your repository

After the first run you'll find a `graphify-out/` folder:

```text
graphify-out/
├── graph.json
├── graph.html
├── GRAPH_REPORT.md
├── manifest.json
└── cache/
```

Open `graph.html` in a browser to explore the graph. Commit `graph.json` and `GRAPH_REPORT.md` if you want teammates and CI to share the same graph; add `cache/` to `.gitignore`.

## Useful skill commands

| Command | What it does |
| --- | --- |
| `/graphify . --update` | Re-extract only new or changed files |
| `/graphify . --mode deep` | Slower extraction with richer `INFERRED` edges |
| `/graphify . --wiki` | Write an agent-readable wiki, one article per community |
| `/graphify path "AuthModule" "Database"` | Shortest path between two concepts |
| `/graphify explain "SessionStore"` | Plain-language explanation of one node |
| `/graphify https://github.com/<owner>/<repo>` | Clone a repository and graph it |

## Verify it worked

```bash
graphify god-nodes --top 5
```

You should see the five most connected symbols in your code. If the command says it can't find a graph, run it from the folder that contains `graphify-out/`, or pass `--graph graphify-out/graph.json`.

<AccordionGroup>
  <Accordion title="The agent doesn't recognise /graphify">
    Restart the agent so it reloads skills. For Claude Code, check that `~/.claude/skills/graphify/SKILL.md` exists. For other agents, re-run `graphify install --platform <name>`.
  </Accordion>
  <Accordion title="Can I skip the LLM step?">
    Yes. Run `graphify extract . --code-only` from a terminal. It builds the code graph with no model calls.
  </Accordion>
  <Accordion title="How do I remove the skill?">
    Run `graphify uninstall`. Add `--purge` to also delete `graphify-out/` in the current folder.
  </Accordion>
</AccordionGroup>
