**Connectors** is where you connect Graphify to the rest of your tools. It has two tabs: **MCP**, for coding agents, and **Integrations**, for source providers, knowledge sources, issue trackers, and CI. Connected sources give reviews and answers more context; none of them gives a verdict on their own.

<Note>
**Use Connectors when** you're setting up an agent, connecting a code provider, or creating a token for a pipeline.
</Note>

## Before you start

- A Graphify account at [app.graphify.com](https://app.graphify.com).
- For workspace tokens, owner or admin rights. Other members need to ask an owner or admin.

## The MCP tab

Pick your coding agent and follow its setup. The tab fills in your endpoint and shows the config file to edit. See [Hosted MCP](/platform/hosted-mcp) for each client.

## The Integrations tab

Integrations are grouped by category. Use **Filter integrations** to find one.

| Category | Examples on the page |
| --- | --- |
| Source control | GitHub and GitLab connections clone for indexing, receive review events, and post results. |
| Knowledge | Documents from Google Drive and other team doc stores. |
| Project management | Issue context for pull requests. |
| Communication | Sharing reviews and questions in channels. |
| Developer tools | Workspace API tokens, error tracking, and CI test selection. |

Which integrations you can connect depends on your workspace. Tiles that aren't available yet are marked as coming.

## Create a workspace token

Some integrations, such as a CI pipeline, authenticate with a workspace token instead of a sign-in.

<Steps>
  <Step title="Open API Token">
    In **Integrations**, open **API Token** and select **Generate a token**.
  </Step>
  <Step title="Copy it now">
    The token is shown once. Copy it straight into your secret store.
  </Step>
  <Step title="Rotate when needed">
    Replacing a token revokes the current one. Update your pipeline secret afterwards.
  </Step>
</Steps>

<Warning>
Never commit a token to a repository or paste it into a chat. Store it as a CI secret.
</Warning>

## Connect a code provider

The top of **Integrations** lists your code providers:

| Provider | Tile text | What it does |
| --- | --- | --- |
| GitHub | Sync repositories and pull requests. | Installs the Graphify GitHub App. After that, **Manage installation on GitHub** chooses which repositories Graphify can see. |
| GitLab | Sync repositories and merge requests. | Connects your gitlab.com account. Self-managed GitLab isn't supported. |

Once a provider is connected, its tile shows **Connected** and the button changes to **Manage**. Graphify clones the repositories you grant, indexes them, gets review events, and posts results back.

## Connect Google Drive

<Steps>
  <Step title="Open the Google Drive tile">
    In **Integrations**, find **Google Workspace · Google Drive** ("Search documents from Google Drive.") and select **Connect Google Drive**.
  </Step>
  <Step title="Sign in with Google">
    Select **Continue to Google**. Access is read-only: Graphify never edits your files.
  </Step>
  <Step title="Choose a folder">
    Select **Choose a Drive folder**, then **Add this folder**. Its documents become searchable in Graphify, and the tile shows **Connected · Syncs automatically**.
  </Step>
</Steps>

Supported files: Google Docs, Sheets and Slides, plus PDF, Word, Excel, PowerPoint, CSV, Markdown, text and image files. Files that can't be read are listed in the folder details. Adding folders needs a paid plan, and only an owner or admin can connect Drive.

If you switch to a different Google account, the folders from the old account stop syncing and you need to add them again.

## Connect Vercel

The Vercel integration connects an existing Graphify workspace to your Vercel projects. Your plan, usage and billing stay with Graphify.

<Steps>
  <Step title="Install from Vercel">
    Add the Graphify integration in Vercel. You're sent to **Connect your codebase context**.
  </Step>
  <Step title="Choose your Graphify workspace">
    Pick a workspace where you're an owner or admin. If you don't have one, select **Create a workspace**.
  </Step>
  <Step title="Choose projects to connect">
    Select the projects. Production deployments receive the connection. Turn on **Also allow preview deployments** only for projects whose preview code you trust.
  </Step>
</Steps>

Each connected project gets two environment variables:

| Variable | Value |
| --- | --- |
| `GRAPHIFY_MCP_URL` | The hosted Graphify MCP endpoint for this project. |
| `GRAPHIFY_MCP_TOKEN` | A project token. Send it as a Bearer token from server-side code only. |

Disconnecting a project revokes its token right away. Removing the integration in Vercel revokes all of its project tokens.

## Slack

Slack is available on every plan, including Free. A workspace owner or admin connects it from the **Slack** tile, and each Graphify workspace links to one Slack workspace. Graphify then answers questions from your code graph, with sources, in direct messages and in the channels you choose.

## Verify and troubleshoot

| Symptom | Fix |
| --- | --- |
| **Reconnect needed** | The provider's access expired. Reconnect it from the tile. |
| You can't create a token | Ask your team owner or an admin. |
| Repositories missing after connecting GitHub | Use **Manage installation on GitHub** to grant the repositories. |
| A draft fix can't be opened | Grant GitHub write access, then select **I've granted access. Re-check**. |
| **Google access expired. Reconnect to keep folders in sync.** | Select **Reconnect Google Drive**. Existing graphs stay available. |
| **Add Google Drive folders with a paid plan.** | Folders need a paid plan. Check **Billing**. |
| **No admin workspaces are available.** (Vercel) | You need to be an owner or admin of a workspace. Create one or ask to be made admin. |
| **No projects are available.** (Vercel) | Update the integration's project access in Vercel, then reopen **Configure**. |
| **Access revoked. Vercel variable cleanup is pending** | Retry cleanup, or remove the Graphify variables in Vercel by hand. |
