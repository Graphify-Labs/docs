**Contributors** connects repository authorship with graph reach and commit-signing evidence. Use it to understand who has worked on heavily depended-on code and where to investigate an ownership or signing question.

Open **Contributors** in [Graphify Cloud](https://app.graphify.com) when it is enabled for your workspace, then choose an indexed repository.

## Inspect ownership and reach

Select a contributor to inspect available authored-node counts, affected graph context, and the most widely depended-on code associated with that identity. Follow source links to investigate the actual change or repository history.

The view can include signing coverage, AI-assist indicators, and advisory risk signals when the repository's contributor overlay contains that information. A metric that was not measured should remain unmeasured rather than being read as zero.

## Interpret the evidence

Git author strings do not by themselves verify a person's identity. Distinguish a resolved account and signed-commit evidence from an unverified name or address.

This is an advisory investigation surface, not an accusation or a measure of developer performance. Read each signal's supporting evidence and follow the relevant commits before drawing conclusions.

## Missing contributor data

The contributor overlay is produced at index time when enabled for the workspace. If the view says there is no overlay yet, check [Repositories and builds](/platform/repositories) and the feature's workspace availability.
