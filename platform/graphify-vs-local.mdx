Graphify is the hosted product. It indexes your repositories on GitHub or GitLab and serves the graph through `https://api.graphify.com/mcp`. Graphify Local is the open-source [`graphifyy`](https://github.com/Graphify-Labs) package. It builds the graph on your machine and writes it to `graphify-out/`.

Both give your assistant the same kind of code graph. They differ in where the graph is built, how it stays current, and what your team can do with it.

## Which one fits

<CardGroup cols={2}>
  <Card title="Choose Graphify" icon="cloud" href="/platform/quickstart">
    Your code is on GitHub or GitLab, and you want the graph kept current on every push, shared with your team, and used for pull request reviews.
  </Card>
  <Card title="Choose Graphify Local" icon="laptop" href="/open-source/quickstart">
    The project exists only on your machine, or you want to build and keep the graph yourself with no account.
  </Card>
</CardGroup>

## Side by side

| Area | Graphify Local | Graphify |
| --- | --- | --- |
| **Graph build** | `/graphify .` or `graphify extract` on your machine | Indexed from the default branch on GitHub or GitLab |
| **Updates** | `graphify update .`, `graphify watch .`, or git hooks | Each push to the default branch |
| **Connection** | `graphify-mcp` over stdio, with a path to `graph.json` | `https://api.graphify.com/mcp` over Streamable HTTP |
| **Sign-in** | None | OAuth in the browser, or an API token for CI |
| **Repository** | One `graph.json` for each entry, or `project_path` | `repository_id` on each call |
| **Tool names** | `get_node`, `get_neighbors`, and `shortest_path` with `source` and `target` | `graphify_node`, `graphify_callers`, and `shortest_path` with `src` and `tgt` |
| **Pull requests** | `list_prs`, `get_pr_impact`, and `triage_prs` through `gh` | Automatic reviews in **Reviews** |
| **Saved lessons** | `graphify-out/reflections/LESSONS.md` | **Memory** for each repository, shared with the workspace |
| **Change impact** | `graphify affected "<node>"` | `graphify_impact` and `impact_and_risk` |
| **Wiki** | `graphify export wiki` writes Markdown files | **Wiki** for each indexed repository, with search and questions |
| **Several repositories** | `graphify merge-graphs` or `graphify global add` | **Cross-Repository** in **Graphs** |
| **Team** | Each clone installs the skill and the hooks | **Members** in the user menu |

## Only in Graphify

- [Pull request reviews](/platform/reviews) against the indexed graph and the diff.
- [Learning](/platform/learning) from `@graphify wrong`, `good`, and `suppress` replies on reviews.
- [Formal verification](/platform/verification) of changed functions against their earlier implementation.
- [Agent memory](/platform/memory) shared by every assistant and teammate in the workspace.
- `graphify_tests_for` and `impact_and_risk`, which list the tests linked to a symbol and rank the files a change reaches.
- [Contributors](/platform/contributors), when it is available in your workspace.

## Switch later

You can start with Graphify Local and move a repository to Graphify at any time. It is a configuration change: your application code stays as it is, and the local graph keeps working until you switch each assistant. Follow [Move from Graphify Local](/platform/support/move-from-local).
