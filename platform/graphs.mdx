**Graph** shows the code knowledge graph of a repository: its modules, files, classes, and functions, and how they connect. Every relationship carries a confidence tag, so you can tell what was read from the code and what was worked out by analysis.

<Note>
**Use the graph when** you want to see the shape of a system, find its most connected code, or check what a change could affect.
</Note>

## Before you start

- A Graphify account at [app.graphify.com](https://app.graphify.com).
- A repository with the status **Indexed**. To combine graphs, you need at least two.

## Read the canvas

| Visual | Means |
| --- | --- |
| Dot color | Code area (community). Colors match the **Code areas** list. |
| Node size | How connected the node is. |
| Edge weight | Certainty of the relationship. |

Select a code area to see its connections, or use **Filter the canvas by code area**. **Most connected** lists the nodes that much of the code depends on. **Graph totals** shows the size of what you're looking at.

## Explore a node

<Steps>
  <Step title="Find it">
    Use **Find a node** to search by name, path, or repository. Prefix with a kind, such as `repo:`, to narrow results.
  </Step>
  <Step title="Read its connections">
    The panel lists **Incoming connections** and **Outgoing connections**. Choose **How many connections to follow** to widen or narrow the view.
  </Step>
  <Step title="Check impact">
    **What a change could affect** lists the possible dependents of the node.
  </Step>
  <Step title="Ask about it">
    **Explain this code** gives a plain-language explanation of the selected node. For a broader question, use [Ask](/platform/ask).
  </Step>
</Steps>

Use **Fit graph to view**, **Zoom out**, full screen, and **Reset layout** (which returns dragged nodes to the computed layout) to move around. **Export the graph** downloads it.

## Combine repositories

Real systems span repositories. A combined graph links entities in different repositories so you can trace a change across them.

<Steps>
  <Step title="Open Combine graphs">
    Go to the cross-repository view and select **Combine graphs**.
  </Step>
  <Step title="Pick repositories">
    Select two or more under **Repositories to combine**.
  </Step>
  <Step title="Name it">
    Enter a name, or leave it blank to use the suggested one.
  </Step>
</Steps>

The combined graph shows **Cross-repo connections** and **Possible cross-repo dependents**. It's saved under **Saved combined graphs**.

### Combined graph limits and states

- A name is 2 to 120 characters.
- A combined graph holds 1 to 100 repositories from your workspace.
- Rebuilding with the same repositories and unchanged graphs doesn't start new work.

A combined graph moves through `not_started`, `queued`, `running`, then `ready` or `failed`. If it fails, select **Retry build**.

## Query the graph

The console, Ask, and your [hosted MCP](/platform/hosted-mcp) agent all query the same graph. Each query targets one repository, by ID, full name such as `acme/api`, or short name such as `api`. A combined graph is targeted by its name.

| Code | Status | Fix |
| --- | --- | --- |
| `repository_required` | 422 | Name a repository. |
| `query_repository_ambiguous` | 422 | Two repositories share that short name. "Use the full repository name or ID." |
| `query_forbidden` | 403 | You can't read that repository. |
| `rate_limited` | 429 | More than 120 queries a minute in this workspace. Wait and retry. |
| `query_timeout` | 504 | The query ran past 45 seconds. Narrow it to a module or symbol. |
| `query_busy` / `query_unavailable` | 503 | Retry after the `Retry-After` header, 1 to 2 seconds. |

See [Troubleshooting](/platform/support/troubleshooting#query-ask-and-reindex-errors).

## Link to a view

The graph reads its URL, so you can share an exact view. It accepts `?repo=`, `?repos=`, `?node=`, `?impact=`, and `?group=`.

## Read the legend

| Visual | Meaning |
| --- | --- |
| Dot color | Code area (community). Select a color to show only that area. |
| Dot size | How connected a node is. |
| Edge weight | Certainty. The legend has three levels: firmly asserted (read from source, or seen at runtime), probably right but not proven (derived, not read verbatim), and loosely asserted (dynamic dispatch, string keys, prose). |

Use **Search nodes by name, path, or repository**. You can narrow a search with `kind:` and `repo:`. Press <kbd>F</kbd> to open the focus lens. Use **Fit graph to view**, **Show the minimap** and **Maximize the graph to full screen** to move around large graphs, and **Reset layout** to put dragged nodes back.

## What a change could affect

Select a node and open **What a change could affect**. Under **How many connections to follow**, choose a depth of 1, 2 or 3 hops. Graphify highlights everything that calls, imports, cites or implements the node within that range.

This is a structural over-estimate. It's not a prediction that anything will break, and it doesn't verify anything. **No dependents found in this view** means nothing in the loaded graph depends on the node.

## Plan limits

Combining graphs needs an active plan. New accounts get a 14-day Pro trial, then move to Free (3 repositories, no card required).

## Verify and troubleshoot

| Symptom | Fix |
| --- | --- |
| **No cross-repository graphs yet** | Combine two or more repositories. |
| **Select at least two repositories.** | A combined graph needs two or more. |
| **The graph could not be refreshed** | Graphify shows the last loaded graph while it reconnects. Reload later. |
| **Could not load combined graphs** | Try again. Your saved graphs aren't deleted. |
| Banner says **Demo graph** | You're looking at sample data, not your code. Index a repository. |
| **Combining graphs needs an active plan.** | Check **Billing**. |
| **We couldn't confirm the combined graph was created.** | Check **Saved combined graphs** before you try again, so you don't create a duplicate. |
| **Graph unavailable** | The build hasn't finished or couldn't start. If you see **We couldn't start this build. Try again.**, start it again. |

<AccordionGroup>
  <Accordion title="What are the confidence tags?">
    Relationships are tagged as read directly from the code or inferred by analysis. See [provenance](/concepts/provenance).
  </Accordion>
  <Accordion title="Can I explore the same graph locally?">
    Yes. Graphify Local writes `graph.html` for a local build. See [Exports](/open-source/features/exports).
  </Accordion>
  <Accordion title="Does a highlighted dependent mean my change breaks it?">
    No. The impact view is a dependency estimate. Use [reviews](/platform/reviews) and your tests to check a real change.
  </Accordion>
</AccordionGroup>
