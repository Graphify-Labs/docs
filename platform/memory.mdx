**Memory** holds your repository's decisions, incidents, and lessons as your coding agents record them, with evidence and history for your team and your agents. Facts are consolidated per code entity, not per conversation, so when an agent edits a function, it recalls what's known about that function.

<Note>
**Use Memory when** you want to know why something is the way it is, what an agent learned in an earlier session, or which facts are tied to code that still exists.
</Note>

## Before you start

- A Graphify account at [app.graphify.com](https://app.graphify.com).
- An indexed repository.
- A coding agent connected through the [hosted MCP](/platform/hosted-mcp). Memories are written by agents, so a new repository has none.

## How it works

<Steps>
  <Step title="Agents record">
    Connected agents write memories over MCP or the HTTP endpoint. Memories are scoped to your workspace.
  </Step>
  <Step title="Distil">
    A model turns raw memories into candidate facts.
  </Step>
  <Step title="Merge by rule">
    Duplicates fold by rule, never by model, so merging is deterministic.
  </Step>
  <Step title="Anchor">
    Each fact is anchored to the code entity it describes when one resolves. Provenance and anchors survive merging.
  </Step>
</Steps>

## Explore memory

<Steps>
  <Step title="Open Memory">
    Open **Memory** in the Console and choose a **Repository**.
  </Step>
  <Step title="Recall">
    Use **Recall a fact, entity, or anchor** to search, or pick from **Memory entities**.
  </Step>
  <Step title="Inspect a fact">
    Read the **Remembered facts** for an entity, with their source turns and the graph node they're anchored to.
  </Step>
</Steps>

The **Memory summary** shows **Entities covered**, how many facts are **Grounded**, and **Tokens saved**.

## Grounded and ungrounded facts

A fact is **grounded** when it's anchored to a code node that still resolves. Ungrounded facts are normal, not errors: a decision about process, or about code since deleted, has nothing to anchor to.

A remembered fact and an extracted code relationship are different kinds of evidence. For the current behaviour, follow the anchor to [Graph explorer](/platform/graphs) and read the code. Explicit instructions and human decisions take precedence over anything inferred.

## How Memory fits with your agent's own memory

Your agent can keep its own preferences and session notes. Graphify adds shared knowledge tied to your repositories that other agents and teammates in the workspace can inspect. Graphify doesn't sync with or replace another memory store.

## Verify and troubleshoot

| Symptom | Fix |
| --- | --- |
| Memory is empty | Select **Connect an agent** and connect one over MCP. |
| **Source turns are unavailable** | The original conversation turns can't be loaded. The fact and its anchor remain. |
| Many facts ungrounded | Expected for process decisions. For code facts, check the code still exists. |
