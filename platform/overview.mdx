Graphify is shared context for your coding agents and your team: a code graph, Memory for decisions and incidents, a Wiki, and cross-repo pull request reviews.

Agents query it at `https://api.graphify.com/mcp`. Your team reads the same context in the [Graphify app](https://app.graphify.com?utm_source=docs&utm_medium=link&utm_campaign=platform-overview). There's nothing to deploy. A workspace is personal, or shared with a team.

## How it works

<HowItWorksDiagram />

Connect GitHub or GitLab. Graphify indexes the default branch into files, symbols, calls and imports. Memory, the Wiki and pull request reviews use that graph, and a push rebuilds it. [How Graphify works](/concepts/how-it-works) covers each stage.

Pull request reviews are on for a connected repository until someone turns them off. See [Review a pull request](/platform/reviews/review-a-pull-request).

## Common tasks

- [Trace who calls this](/open-source/features/trace): callers of a symbol, and what a change can reach.
- [Review a pull request](/platform/reviews/review-a-pull-request): run a review, run it again with `@graphify review`, and mark which findings were right.
- [Read a review and a verdict](/platform/reviews/read-a-result): what a finding and a verification result mean.
- [When something fails](/platform/support/faqs): an empty graph, a failed build, or a plan limit.

## Graphify and Graphify CLI

Graphify is the hosted workspace. [Graphify CLI](/open-source/quickstart) (`graphifyy`) runs the graph on your machine. [Compare them](/platform/graphify-vs-local), or [move a repository](/platform/support/move-from-local) from the CLI to Graphify.

Formal verification is part of Graphify. What you can use depends on your workspace and plan. See [plans and pricing](/platform/support/pricing), including [Enterprise](/platform/support/pricing#enterprise) for self-hosting, SSO/SAML, GitHub Enterprise, and procurement.

Some workspaces ask **What would you like to do first?** You can skip it. **Settings → Your experience** changes that goal, adds a work role, or sets **Only when I ask**. Structure and pattern discovery roll out separately and need a compatible index. Missing coverage is shown explicitly. Graphify and Graphify CLI can show different capabilities. Follow what your setup shows.
