**Wiki** turns an indexed repository into a browsable knowledge base: its subsystems, its load-bearing abstractions, and how they connect. Pages are generated from the code knowledge graph, and each one keeps a confidence trail, so you know which statements were read from the code and which were inferred.

<Note>
**Use the wiki when** you're onboarding to a repository, explaining it to someone new, or looking for the right place to start reading code.
</Note>

## Before you start

- A Graphify account at [app.graphify.com](https://app.graphify.com).
- An indexed repository. The wiki is generated from a build, so a new repository shows **No wiki for this build yet** until its build finishes.
- **Wiki** in your workspace navigation. If you don't see it, it isn't turned on for your workspace.

## Read the wiki

<Steps>
  <Step title="Open it">
    Open **Wiki** in the Console and choose a **Repository**.
  </Step>
  <Step title="Pick an article">
    The **Articles** index lists every page. Use **Search pages** or **Find in the wiki** to jump to a topic.
  </Step>
  <Step title="Read">
    Each article has **Key components**, diagrams you can expand, and **Relevant source files**. **On this page** lists its sections, and **Previous page** and **Next page** move through the wiki in order.
  </Step>
  <Step title="Go to the code">
    **Open the source** opens the file. **Show in the graph** opens the component in [Graph explorer](/platform/graphs).
  </Step>
</Steps>

Turn on **Reading mode** to hide the surrounding Console while you read.

## Confidence labels

| Label | Means |
| --- | --- |
| Verified | Read directly from the code. |
| Inferred | Worked out by analysis. |
| Needs review | A low-confidence guess. Check the source. |

## Ask the wiki

Select **Ask the wiki** (or **Ask about this project**) and type what you'd like to understand. Answers draw on the same graph as the wiki. For questions about one function or call path, [Ask](/platform/ask) is more direct.

## Large repositories

For a very large graph, the wiki covers only its largest areas, and some cross-links may not resolve. If a wiki is **too large to load**, contact support to raise its size limit.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| <kbd>R</kbd> | Hide the sidebars and read full screen |
| <kbd>Esc</kbd> | Exit reading mode |
| <kbd>]</kbd> or <kbd>J</kbd> | Next page |
| <kbd>[</kbd> or <kbd>K</kbd> | Previous page |

Each page lists its **Relevant source files** and **Key components**. Use **Open the source** to see the code, or **Show in graph** to find it in [Graph explorer](/platform/graphs). When the wiki is **Behind the latest commit**, it shows **Updating to the latest commit** while a new build runs.

## Starter questions

**Ask about this project** opens a panel with starter questions. You don't need code terms:

- "What does this project do? Explain it in plain language."
- "What are the main parts of this project, and how do they work together?"
- "Where does a request or user action start in this project?"

Answers use the indexed code and say when evidence is missing.

## Wikis for Google Drive folders

A synced [Google Drive](/platform/connectors) folder gets a wiki too, built from its documents. Its states read **Sync in progress**, **Folder not synced** and **Folder sync failed**, instead of the repository states. **Google Drive syncing requires a paid plan.**

## Verify and troubleshoot

| Message | What to do |
| --- | --- |
| **No repositories yet** | Connect and index a repository to generate its wiki. |
| **No wiki for this build yet** | Wait for the build to finish. |
| **Wiki temporarily unavailable** | Try again in a moment. |
| **Wiki is locked** | Update your subscription to restore wiki access. |
| **Wiki is too large to load** | Contact support to raise the size limit. |
| **Indexing paused** | Select **Resume indexing**. |
| **Repository indexing failed** | The last index didn't finish. Index the repository again. |
| **Google Drive needs reconnecting** | Select **Reconnect Google Drive**, then sync the folder. |
| **This is a large graph. The wiki only covers its largest areas.** | Expected for very large repositories. Some cross-links may not resolve. |

<AccordionGroup>
  <Accordion title="How current is the wiki?">
    It reflects the latest build of the repository. Check the build metadata on the page.
  </Accordion>
  <Accordion title="Can I generate a wiki locally?">

  </Accordion>
  <Accordion title="What do Verified, Inferred and Needs review mean?">
    Verified means read directly from the code. Inferred means worked out by analysis. Needs review means a low-confidence guess, so check the source.
  </Accordion>
</AccordionGroup>
