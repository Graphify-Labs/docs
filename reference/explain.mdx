---
title: "graphify explain"
description: "Inspect a concept, its source, and the relationships around it."
hideFooterPagination: true
---

```bash
graphify explain "<node>" [--graph <path>]
```

Give the command a label or node identifier from a query result. It returns details about the node and its graph context.

```bash
graphify explain "normalize_email"
graphify explain "YourNodeId" --graph ./shared/graph.json
```

Look for the source file, community, and relationships connected to the node. Available fields depend on the extractor. If several concepts have similar names, use the precise ID returned by the graph.

Optional [work-memory](/guides/work-memory) overlays can add lesson hints. Check for stale-source warnings and re-verify a lesson after code changes.

For native MCP access, use `get_node` followed by `get_neighbors` when you need the surrounding edges.
