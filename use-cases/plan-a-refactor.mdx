You need to change something many parts of the code depend on: a core function, a data shape, a module boundary. The risk is the code you don't know about. Graphify shows what a change reaches before you make it, and reviews the pull request against the same graph after.

This walkthrough uses the open-source [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) repository, with `build_from_json` as the function to change.

## Walk through it

<Steps>
  <Step title="Map what the change reaches">
    With the repository **Indexed** ([Index your first repository](/concepts/index-a-repository)) and your agent connected ([Claude Code](/integrations/claude-code-mcp), [Cursor](/integrations/cursor-mcp), [Codex](/integrations/codex-mcp) or [VS Code](/integrations/vscode)), ask:

    ```text
    Use Graphify on Graphify-Labs/graphify: I want to change build_from_json.
    What does that reach, which files are riskiest, and which tests cover them?
    ```

    See [Check the impact of a change](/concepts/check-impact).
  </Step>
  <Step title="Follow the callers">
    Ask what calls `build_from_json`, and trace how `extract` reaches it. See [Follow calls and trace a path](/concepts/follow-calls).
  </Step>
  <Step title="Look for code you can remove">
    Expand the repository row on **Repositories** to see **Unreferenced code (heuristic)**. Code reached through reflection, a string lookup, or another repository can still appear, so check before you delete it.
  </Step>
  <Step title="Split the change and review it">
    Open the refactor as small pull requests. Each gets a review. Where verification ran, each supported changed function is proved equivalent, shows a behavior change with the input that triggers it, or has no verdict. See [Review a pull request](/concepts/review-a-pull-request) and [Read a review and a verdict](/platform/read-a-result).
  </Step>
</Steps>

Impact results list direct connections. Code called dynamically, or tested in a way the graph does not link, may not appear. Run your tests.

## Do it locally instead

```bash
graphify extract . --code-only
graphify explain "build_from_json"
graphify path "extract" "build_from_json"
graphify query "what depends on build_from_json" --budget 1500
```

After the refactor, rebuild with `graphify update . --force`. See [Keep the graph current](/guides/incremental-updates).
